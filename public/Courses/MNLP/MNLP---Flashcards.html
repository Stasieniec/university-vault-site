L01 Overview

Flashcards

Which three fields does NLP sit at the intersection of?

Computer science, artificial intelligence, linguistics.

What distinguishes spoken from written language as a signal?

Spoken language is continuous; written language is discrete.

What distinguishes structured from unstructured information?

Structured: tables, databases. Unstructured: language, images, video.

Which types of entity does named entity recognition usually identify?

Persons, organisations, dates, locations.

Is NER harder for English or for other languages?

Other languages. For English it seems trivial, though it still makes silly mistakes.

What did summarization systems traditionally use to decide what is important?

Frequency-based term weights from information retrieval.

Which two abilities does machine translation require?

Understanding the source sentence and generating sentences in the target language.

In which roles can LLMs substitute or supplement humans?

Data annotation, evaluation (LLM as a judge), dialog.

Why are most state-of-the-art LLMs English-centric?

They are trained predominantly on Internet resources, where English dominates.

How does the performance of general multilingual LLMs such as Llama 3.1 and DeepSeek vary across languages?

They do better on high-resource languages.

What is the difference between multilingual and crosslingual NLP?

Multilingual: one system works for many languages. Crosslingual: information or knowledge crosses between languages.

Which traditional NLP tasks do LLMs carry out end to end?

Question answering, document summarization, machine translation.

What distinguishes crosslingual QA from ordinary QA?

The answer must be extracted from resources in another language.

True or false: In pre-deep-learning NLP, each application required a different approach.

True. Each application combined its own ML method and features.

True or false: Sentiment analysis operates only at the document level.

False. It operates at both the sentence and the document level.

True or false: Crosslingual unlearning asks how to combine information across languages.

False. Unlearning asks how to manipulate information across languages; reasoning combines it.

True or false: Dedicated multilingual models such as Aya-Expanse outperform general LLMs such as Llama 3.1.

False. Dedicated multilingual models tend to lag behind (read as behind the general models).

True or false: LLMs originated within NLP.

True. They originated within NLP and now dominate its research landscape.

True or false: Summarization works on a single document or on several.

True. It keeps the most important content of one document or several, so a reader can browse quickly.

Multiple selection: which are crosslingual scenarios? (A) Machine translation (B) Language-independent parsing (C) Crosslingual reasoning (D) Sentence classification across languages

A and C. B and D are multilingual: their question is how to build one system that is not language-specific.

Multiple selection: which are true of deep learning in NLP? (A) It needs very little or no feature engineering (B) It works well with small amounts of training data (C) Its errors are easy to trace (D) Insights transfer to vision and speech because network types are uniform

A and D. B is false: it needs large amounts of data. C is false: errors are hard to trace.

Multiple selection: which are true? (A) QA returns a ranked list of documents (B) Sentiment analysis requires named entity recognition (C) Machine translation typically translates individual sentences (D) LLMs are used to evaluate outputs as judges

B, C and D. A is false: IR returns ranked documents; QA returns the actual answer.

L02 Multilinguality and Writing Systems

Flashcards

How do most non-English NLP resources come about?

As by-products (translations, reviews) or translations of English resources; less often as dedicated efforts.

Why do claims that an NLP method is "language independent" deserve suspicion?

They are usually untested outside English or a very small set of languages.

What does it mean for a language such as Finnish to be agglutinative?

Morphemes are glued on in sequence, each adding one piece of meaning.

Which four English-first assumptions are built into standard NLP pipelines?

Words separated by whitespace; grammar encoded by word order; one word = one meaning; text flows left to right.

Why do word-position features carry little information in Russian, Finnish or Korean?

Grammatical relations are marked by case on the noun, so word order is flexible.

Which two kinds of language break the assumption "one word = one unit of meaning"?

Agglutinative languages (Finnish, Turkish, Hungarian) and compounding languages (German, Dutch, Swedish).

In Arabic or Hebrew text, is the first character of the Unicode string the leftmost one on screen?

No. Text is stored left to right in reading order but rendered right to left.

Which type of writing system has each symbol represent a consonant or vowel sound?

Alphabetic (Latin, Cyrillic, Hangul), typically a small inventory.

What does each symbol represent in a syllabic writing system such as Hiragana or Katakana?

A whole syllable, a combination of consonant and vowel.

What does each symbol represent in a logographic writing system such as Chinese Hanzi?

A word or morpheme directly, with little sound information.

How did code pages extend ASCII?

By reinterpretation: the same 128 or 256 byte codes, read differently per language or script.

What is Unicode?

A single universal character set giving every character it encodes, in every supported script, one unique number, its codepoint (U+number).

How does Unicode relate to ASCII?

Unicode is a superset: U+0000 to U+007F are identical to ASCII.

What is the difference between a codepoint, a character and a glyph?

Codepoint: abstract number. Character: what a reader perceives, possibly several codepoints. Glyph: a stylistic rendering.

Which form do you end in after canonical decomposition followed by composition?

NFC (compatibility decomposition then composition gives NFKC).

Which normalization form should you use for search indexing or NLP analysis?

NFKD.

Which Unicode encoding uses exactly 4 bytes for every codepoint?

UTF-32: simple for indexing, memory-hungry, rare in practice.

Which of UTF-8, UTF-16 and UTF-32 is ASCII compatible?

Only UTF-8; the other two use at least two bytes per character.

In UTF-8, what does a byte starting with 0 signal?

A complete single-byte character (ASCII).

What is a UTF-8 byte of the form 10xxxxxx?

A continuation byte inside a multi-byte sequence.

How is byte inflation defined for byte-level tokenizers?

UTF-8 bytes of a string divided by its number of perceived characters.

Which has the highest byte inflation: "hello", "café" or "中文"?

中文: 3 bytes per character, against 1 per character for “hello”.

Which preprocessing steps go wrong when crawled text mixes NFC and NFD?

Deduplication, search, string equality and prefix matching: all assume identical codepoint sequences.

What is the fix for crawled data that mixes normalization forms?

Consistent normalization in the pipeline, e.g. first decompose, then compose.

Why does lowercasing the letter I go wrong for Turkish?

Turkish lowercase I is dotless ı; dotted İ pairs with i. English rules change the word.

Why can strings not be sorted alphabetically by codepoint?

Accented letters’ codepoints are not necessarily near their base letter’s.

How do Swedish and German differ in sorting å, ä, ö?

Swedish puts them after z as separate letters; German interleaves them (ä as ae).

Why is punctuation normalization (“...” against «...» against 「...」) hard?

There is no simple solution: the mappings between traditions must be encoded by hand.

True or false: Unicode defines both each character's codepoint and how it is stored as bytes.

False. Unicode defines codepoints only; bytes are the job of an encoding such as UTF-8.

True or false: How well a language is covered by NLP resources depends mainly on its number of speakers.

False. It depends on commercial interest and military relevance.

True or false: NFKD normalization is lossless.

False. Compatibility forms are lossy (ſ becomes s); only the canonical forms NFC and NFD are lossless.

True or false: NFKD normalization makes the ligature ﬁ and the pair fi identical.

True. Compatibility decomposition splits ligatures, which is why NFKD suits search indexing.

True or false: The form to use for comparing rendered text is NFD.

True. NFD is non-lossy and preserves semantic and visual equivalence; NFKD is for search and analysis.

True or false: Code pages allow only one script per document.

True. A document is read with one table, so scripts cannot be mixed.

True or false: NFC and NFD versions of "café" render identically but are unequal as strings.

True. Same appearance, different codepoint sequences (4 against 5 codepoints).

True or false: Byte-level tokenizers tend to split text more aggressively in scripts that need more UTF-8 bytes per character.

True. More bytes per character means more pieces per character.

True or false: In Unicode, every character a reader perceives has exactly one codepoint.

False. A perceived character (grapheme) can be several codepoints, such as e plus a combining accent.

True or false: Whitespace tokenization works for Thai because Thai uses spaces between words.

False. Thai spaces end clauses or sentences, not words.

Multiple selection: which languages break the assumption that words are separated by whitespace? (A) Thai (B) Russian (C) Khmer (D) German

A and C. Russian breaks the word-order assumption; German breaks one-word-one-meaning through compounding.

Multiple selection: which are true of script and language? (A) Serbian is written in Cyrillic and Latin (B) Arabic script identifies the Arabic language (C) Armenian has a language-specific script

A and C. B is false: Arabic script also writes Persian, Urdu, Pashto and Sorani.

Multiple selection: which are true of Unicode normalization? (A) NFC and NFD are lossless (B) NFKD is the recommended form for generation targets (C) NFKD maps the long s ſ to s (D) NFD merges a base letter and combining mark into one codepoint

A and C. B is false: NFKD is for analysis, not necessarily generation. D is false: NFD decomposes; NFC composes.

Multiple selection: which are true of UTF-8? (A) It uses 1 to 4 bytes per codepoint (B) The number of leading 1s in a lead byte gives the sequence length (C) Emoji fit in 3 bytes (D) From a random offset you cannot tell whether you are at a character start

A and B. C is false: plane-1 emoji need 4 bytes. D is false: continuation bytes start with 10, so a character start is recognisable.

Multiple selection: which are true of string breaking? (A) Byte-level breaking can produce fragments that are not characters (B) Codepoint-level breaking always keeps a diacritic with its base letter (C) Grapheme boundaries are language-specific (D) Mixing breaking strategies across corpora is harmless

A and C. B is false: e and a combining accent are two codepoints and can be split. D is false: spans misalign and counts become incomparable.

L03 Morphology and Word Formation

Flashcards

What is the difference between a vocabulary and a lexicon?

A vocabulary is an inventory of word forms; a lexicon also stores the meanings and functions of the words.

What is the difference between word segmentation and subword segmentation?

Word segmentation finds word boundaries in scripts that do not mark them (Chinese); subword segmentation splits already delimited words into smaller units (Finnish).

Why are hand-built lexical resources like WordNet a poor basis for word meaning at scale?

They are expensive (every relation entered by hand), incomplete, and language-specific.

What four properties define word embeddings?

Low dimensional, dense, continuous, and learned by performing a prediction task.

How does the CBOW task differ from n-gram language modelling?

A language model sees only the left context; CBOW sees both sides, because its goal is embeddings and prediction is only the means.

Why does vocabulary size ∣V∣ drive the memory footprint of a neural model?

Weight matrices are fixed size, and the output layer has one row per vocabulary word plus a softmax over ∣V∣ at every position.

What is a vocabulary short-list?

Keeping only the most frequent words and mapping every rare word to a single <unk> token.

Why can a word-level model not see that move and moved are related?

They are unrelated indices, so the relation must be learned from data separately for every inflected pair.

How could morphology give a representation for an unseen word like hammered?

Compose it from known parts: an embedding for hammer plus what -ed does to a verb. Context cannot help, since the word was never seen.

How does Backward Maximum Matching differ from Forward Maximum Matching?

It starts at the end, takes the substring ending at position i, and prepends each word so output stays in reading order.

With vocabulary {研究, 研究生, 生活, 生, 活}, what does Forward Maximum Matching return for 研究生活?

研究生 | 活

With vocabulary {研究, 研究生, 生活, 生, 活}, what does Backward Maximum Matching return for 研究生活?

研究 | 生活

How does bidirectional maximum matching decide when FMM and BMM disagree?

A tie-breaking heuristic: prefer fewer total words or fewer single-character words. If they agree, accept with high confidence.

Why can no direction-based heuristic segment correctly in general?

Some strings have several correct segmentations depending on meaning and context, which a scan direction cannot know.

How is word segmentation reformulated for statistical methods?

As sequence labelling: tag each character with its role in a word (BMES).

What do the BMES tags stand for?

Begin, Middle, End, Single.

Which BMES tag only occurs in words of three or more characters?

M (Middle), for an interior character.

In an HMM word segmenter, which sequence is hidden?

The BMES tag sequence, which generates the observed characters.

How are BMES HMM parameters estimated from a segmented corpus?

Maximum likelihood from counts: e.g. a transition is the tag-bigram count divided by the count of the previous tag.

Why can no fixed vocabulary be closed over morphology?

Morphological processes are productive: they apply iteratively and to new combinations (doomscrolled), so new forms keep appearing.

What is a morpheme?

The smallest meaning-carrying part of a word.

What is the difference between free and bound morphemes?

Free morphemes can stand alone as words (book); bound morphemes cannot (dis-, -ed).

Why can a circumfix like German ge-seh-en not be analysed by stripping a prefix or a suffix?

ge- and -en are one morpheme in two pieces, attached front and back simultaneously, so neither half can be stripped alone.

In an isolating language, what carries the grammatical relations?

Word order, with particles for additional modification.

Which morphological type has a single suffix encode several grammatical features that cannot be separated?

Fusional (Russian, Spanish, Arabic).

Which morphological type packs verb, subject, object and modifiers into a single word?

Polysynthetic (Inuktitut, Mohawk).

Are agglutinative morpheme boundaries always clean at the character level?

No: a suffix may change spelling to fit the stem; the meanings still split cleanly.

Why are morphological analysers not the general fix for vocabulary blow-up?

They are highly language dependent: one per language, each built with linguistic expertise.

True or false: CBOW's projection layer loses the order of the context words.

True. It sums the vectors, and summation is commutative.

True or false: Forward and Backward Maximum Matching always produce the same segmentation given the same vocabulary.

False. On ambiguous strings they often disagree (研究生 | 活 against 研究 | 生活).

True or false: Maximum matching flags out-of-vocabulary words in its output.

False. OOV words are silently chopped into single characters or mismatched.

True or false: Viterbi decoding of BMES tags runs in time linear in the sentence length.

True. It is O(n∣T∣2), and ∣T∣=4 is fixed.

True or false: In a BMES HMM, the emission probability is the probability of the character given the tag.

True. Emission is P(ci​∣ti​), not the tag given the character.

True or false: A fixed word vocabulary sized for English produces massive OOV rates for morphologically rich languages.

True. Each lemma has many surface forms, so most forms fall outside the vocabulary.

True or false: Agglutinative languages differ from fusional languages mainly in having more morphemes per word.

False. The defining difference is separability; more morphemes per word is only a consequence.

True or false: Subword segmentation recovers the morphemes of non-concatenative forms such as German Bücher.

False. It only cuts contiguous pieces, so it fully handles only the concatenative case.

True or false: An HMM word segmenter needs a fixed dictionary of possible words.

False. It works over characters; maximum matching is the method that needs a dictionary.

True or false: Inflection keeps a word's part of speech.

True. It changes only features such as number and tense.

True or false: Apophony is a kind of concatenative morphology.

False. It changes a vowel inside the root (Buch → Bücher), so it is non-concatenative.

True or false: Arabic is classed as a fusional language.

True. One root-and-pattern template fuses person, gender and aspect.

True or false: With a vocabulary short-list, rare words keep distinct probabilities in a given context.

False. They all map to <unk>, so all rare words receive equal probability.

True or false: In CBOW the summed context vectors go from the projection layer straight to the output layer.

True. There is no non-linear hidden layer in between.

True or false: Subword tokenization that falls back to single characters guarantees a zero OOV rate.

False. OOV becomes very rare, but unseen characters stay unknown; only byte-level vocabularies guarantee zero.

Multiple selection: which are true of Forward Maximum Matching? (A) It takes the longest vocabulary word at each position (B) It improves as it sees more text (C) It always terminates because a single character is emitted as fallback (D) It needs no precompiled vocabulary

A and C. B: it has no mechanism to exploit data. D: it depends entirely on a precompiled vocabulary.

Multiple selection: which are true of BMES tagging with an HMM? (A) A word boundary follows every E and every S (B) B can be followed by another B (C) Viterbi keeps a backpointer to each cell's best predecessor (D) The model conditions on arbitrary features of the whole input

A and C. B: a word opened by B must continue with M or close with E. D: that describes CRFs; the HMM is first-order.

Multiple selection: which are true of morphological types? (A) In Turkish, each agglutinative suffix carries one meaning (B) Russian -ami fuses instrumental case and plural (C) Isolating languages mark tense mainly by inflecting the verb (D) In a polysynthetic language one word can express a whole sentence

A, B and D. C: isolating verbs do not change form; tense comes from particles and adverbs.

Multiple selection: which are true of HMM word segmentation? (A) A tag depends only on the preceding tag and the current character (B) It cannot be trained without a segmented corpus (C) CRFs address its lack of longer-range context (D) It resolves ambiguity with tie-breaking heuristics

A and C. B: Baum-Welch trains it unsupervised, at a cost in quality. D: that is bidirectional matching; the HMM uses probabilistic evidence.

Multiple selection: which are correct? (A) books is an inflection of book (B) imperfect is an inflection of perfect, since the POS stays (C) Tischbein is a compound (D) happiness is derived from happy

A, C and D. B: imperfect is derivation; derivation changes the POS and/or the meaning.

L04 Subword Segmentation

Flashcards

Which two properties of the training data determine how well a word is represented in NMT?

Its frequency and the number of different contexts it occurs in.

Which two word-formation processes produce many of the word occurrences a fixed word vocabulary handles badly?

Inflection (tall, taller, tallest) and compounding.

What two kinds of unit can a subword be?

A character n-gram, or a morphologically meaningful unit (language dependent).

What are the three weaknesses of hand-built FST morphological analyzers?

Extremely laborious to produce, totally language dependent, no preference among ambiguous analyses.

Which data-driven morphological segmenter is based on the Minimum Description Length principle?

Morfessor (Creutz and Lagus).

Minimum Description Length minimises the sum of which two costs?

The cost of the model itself plus the cost for the model to generate the data.

Which three simplifications do current data-driven subword segmenters make?

No labelling (a split only), no character substitutions or deletions, strictly concatenative.

What two practical properties do data-driven subword segmenters gain from their simplifications?

No annotation or linguistic knowledge needed, and they can be fitted to a desired vocabulary size.

Which pair does BPE merge at each training step?

The most frequent adjacent symbol pair, counted over word types weighted by frequency.

What three major advantages does BPE bring to NMT, compared with word-level vocabularies?

Smaller vocabulary, better translation quality, far fewer OOV items.

What are the four properties of Unigram LM (Kudo)?

Considers all segmentations, optimises the best global one, supports multiple segmentations, top-down.

How does Unigram LM score a segmentation x=(x1​,…,xM​)?

P(x)=∏i​p(xi​): subwords are assumed independent.

What does the token loss Lt​ measure in Unigram LM vocabulary construction?

How much corpus likelihood drops if token t is removed and its strings are re-segmented.

How many segmentations does a string of n characters have?

2n−1: each of the n−1 gaps is either a cut or not.

What two ingredients are needed to score candidate segmentations?

Scores for segments and a way to combine them; in the unigram model, p(x) and multiplication.

What are the two principles of dynamic programming?

Solve each sub-problem only once and store its solution: a time-memory trade-off.

In bottom-up DP segmentation, what does the cell m[i,j] hold?

The score of the best segmentation of the span c[i..j].

How can you get more than the single Viterbi segmentation?

Yen’s or Eppstein’s n-best algorithms, or disallow certain sub-solutions and search again.

What do standard BPE implementations assume about their input that SentencePiece does not?

Word boundary detection: the text is already split into words.

What is the desegmentation problem?

Tokens like [Hello] [world] [.] do not record where spaces were, so detokenizers guess per language.

Which of BPE and Unigram LM finds real morpheme boundaries in words like corrupted and tricycles?

Unigram LM (corrupt|ed, cycle|s); BPE produces frequency artefacts.

In English, how do BPE and Unigram LM differ in how they use the bottom of their vocabulary?

BPE fills it with near-unused tokens; Unigram LM keeps more tokens of moderate frequency.

What two things can still cause OOVs under BPE or Unigram LM?

Typos (sometimes) and unknown characters.

What three factors influence fertility for a language?

Merge count or target vocabulary size, average surface word length, morphological richness.

What three costs does high fertility bring a language?

Harder meaning reassembly, higher API cost, faster context exhaustion.

Why do some languages end up with high fertility under a shared multilingual vocabulary?

No single tokenization scheme dominates across all languages and scripts.

True or false: Unigram LM builds its vocabulary bottom-up, merging pairs until it reaches the desired size.

False. It works top-down, pruning a large seed vocabulary to size k.

True or false: Applying a trained BPE model replays the learned merges in the order they were learned.

True. The model is an ordered merge list.

True or false: BPE's advantages in vocabulary size, OOV rate and translation quality apply only to low-resource language pairs.

False. They apply to both high- and low-resource pairs.

True or false: Data-driven subword segmenters account for character substitutions such as city/cities.

False. They do not account for substitutions or deletions; they are strictly concatenative.

True or false: Unigram LM returns only a single segmentation per word.

False. It supports multiple segmentations: n-best lists and sampling.

True or false: In Unigram LM vocabulary construction, the tokens with the highest loss Lt​ are removed each round.

True. As the algorithm is given for MNLP (labelled Kudo 2018); Kudo’s paper and SentencePiece’s code remove the smallest.

True or false: DP segmentation under a unigram model is valid because segments are treated as independent.

True. The best cut of one half does not depend on the other.

True or false: In DP segmentation, each cell is initialised with the probability of the unsplit span.

True. Split points then replace it only if they score higher.

True or false: Bottom-up DP has a better asymptotic run time than top-down DP with memoization.

False. Both have the same asymptotic run time.

True or false: SentencePiece treats its input as a raw stream of Unicode characters, including spaces.

True. The space is escaped as ▁.

True or false: Byte-level BPE gives non-Latin scripts shorter subsegments because those languages are morphologically richer.

False. Because their characters take more UTF-8 bytes.

True or false: At the same vocabulary size, Unigram LM produces longer segments on average than BPE.

True. In both English and Japanese.

Multiple selection: which are true of BPE? (A) It is greedy: a merge is never undone. (B) It can sample alternative segmentations of a word. (C) Its only hyperparameter is the number of merges. (D) It starts from a large vocabulary and prunes it.

A and C. B: BPE is deterministic. D: that is Unigram LM; BPE merges up from characters.

Multiple selection: which are true of SentencePiece? (A) It is an algorithm distinct from BPE and Unigram LM. (B) It escapes the space as a visible symbol ▁. (C) It requires a language-specific pre-tokenizer. (D) Its segmentation is lossless.

B and D. A: it is a toolkit implementing both. C: raw-stream input removes the pre-tokenizer.

Multiple selection: which are true of byte-level BPE? (A) Its base alphabet has 256 symbols. (B) It cannot encode a script unseen in training. (C) Scripts with more bytes per character get shorter subsegments. (D) It operates on Unicode characters.

A and C. B: any script can be encoded byte by byte. D: it operates on raw UTF-8 bytes.

Multiple selection: which are true of fertility? (A) It is subword tokens divided by words. (B) It depends only on the vocabulary size. (C) High fertility fills fixed context windows faster. (D) Agglutinative languages tend to have lower fertility than isolating Latin-script languages.

A and C. B: word length and morphological richness matter too. D: their many rare word forms get split further.

Multiple selection: which are true of Bostrom and Durrett's BPE against Unigram LM comparison? (A) Unigram LM wins English tasks by a large margin. (B) Unigram LM's advantage is much larger on Japanese TyDi QA. (C) Both tokenizers had the same vocabulary size. (D) BPE recovers more English morpheme boundaries.

B and C. A: the English gains are small, under 1.5 points on every task. D: Unigram LM has higher precision and recall against CELEX2.

L05 Static Embeddings

Flashcards

What does "static" mean for Word2Vec, GloVe and fastText embeddings?

One vector per word type, whatever the sentence: bank is the same in river bank and bank account.

What is the distributional hypothesis behind both count-based and prediction-based word vectors?

A word is characterised by the contexts it occurs in (Firth: “the company it keeps”).

What are the three properties of count-based context vectors?

High-dimensional, discrete (counts), sparse (mostly zeros).

What is the main weakness of count-based context vectors besides sparsity?

No explicit criterion to separate signal from noise: chance co-occurrences, and words like the that discriminate nothing.

What four properties distinguish prediction-based word embeddings from count-based context vectors?

Low-dimensional, dense, continuous, and learned by performing a prediction task.

What is representation learning?

Training where learning good embeddings is the main objective, the task being a pretext. In most models embeddings are by-products.

What is the difference between the CBOW and Skip-gram tasks?

CBOW predicts the centre word from its context. Skip-gram predicts each context word from the centre word.

Are Word2Vec's input matrix W and output matrix W′ tied together?

No, not necessarily: W′=W⊤.

Which matrix is typically used as the Word2Vec embedding?

W (its columns), or the combination W⊤+W′.

What independence assumption does Skip-gram make?

The context words are independent given the input (centre) word.

In negative sampling, what is the probability that a (word, context) pair is real?

σ(vc​⋅vw​): the sigmoid of the dot product of the context and word vectors.

Which tends to perform better: count-based or prediction-based word representations?

Prediction-based. Count-based methods use global information directly but tend to perform worse.

What is the purpose of GloVe's weighting function f(Xij​)?

To de-emphasise very rare (noisy) and very frequent (uninformative) co-occurrences.

What is the difference between Word2Vec and GloVe in what they train on?

Word2Vec: individual local context windows. GloVe: the global co-occurrence matrix.

How do Word2Vec and GloVe differ in handling frequency imbalance?

Word2Vec subsamples frequent words. GloVe uses the explicit weighting function f(Xij​).

What is the difference between intrinsic and extrinsic evaluation of word embeddings?

Intrinsic: the embeddings by themselves. Extrinsic: their usefulness in downstream tasks.

How is word similarity evaluated against human judgements?

Rank word pairs by cosine and compare with human ratings by Spearman (rank) correlation.

What is the difference between the WS-353 and SimLex-999 benchmarks?

WS-353 annotates relatedness (bread/butter high). SimLex-999 annotates similarity in the strict sense.

How is the answer to "a is to b as c is to X" computed with word embeddings?

The word nearest by cosine to vb​−va​+vc​, excluding the input words. Scored by accuracy.

Why should 2D t-SNE plots of embeddings not be taken at face value?

Non-linear projections distort distances, and t-SNE hyperparameters substantially change the picture.

Why do morphologically rich languages suffer most from one vector per word type?

Each lemma has many inflected forms, each a separate, rarer word with a worse-estimated vector.

Where does fastText gain most on word similarity over Word2Vec?

In morphologically rich languages; it also helps rare words.

What are the three basic set-ups for training crosslingual embeddings?

Separately, then align spaces; together, then align regions; on word- or sentence-aligned data.

Why is the crosslingual mapping assumed to be linear?

Analogies are already linear regularities within one space, assumed to hold across spaces.

What bilingual signal does each type of crosslingual alignment use?

Supervised: thousands of seed translations. Semi-supervised: hundreds, then bootstrapping. Unsupervised: none.

Why can seed dictionaries contain only single words?

There are no embeddings for multi-word expressions, so phrases cannot be anchors.

What is the difference between solving the least-squares mapping in closed form and with SGD?

Closed form is exact. SGD is approximate but scales better and saves memory; Mikolov et al. used SGD.

Which mapping does the name "Procrustes" refer to?

Monz: the general least-squares problem. Literature and Conneau et al.’s tables: the orthogonal map solved by SVD.

How does linear-mapping translation accuracy change for rarer words?

It drops: rarer words have worse embeddings.

Why does an unconstrained mapping W overfit the seed dictionary?

It can stretch, shear and rotate the space to fit the seed pairs, and generalises poorly.

What mismatch between training and inference does the unconstrained mapping have?

Training minimises Euclidean distance, retrieval uses cosine. They agree only for unit-normalised vectors.

What constraint and normalisation define Xing et al.'s orthogonal mapping?

W⊤W=I, with all embeddings normalised to unit length.

How is the orthogonal Procrustes mapping solved?

Exactly by SVD: UΣV⊤=SVD(YX⊤), W=UV⊤.

How does the orthogonal mapping compare with the unconstrained one across embedding dimensions?

Better at every dimension, and it improves slightly as dimension grows.

What is a hub in a high-dimensional embedding space?

A vector that is the nearest neighbour of many points regardless of actual similarity.

How does CSLS retrieval compare with plain nearest neighbour on the same supervised mapping?

CSLS is better on every language pair, with no tuning beyond K.

What is the chicken-and-egg problem of unsupervised crosslingual alignment?

You need a mapping to find translation pairs, and translation pairs to learn the mapping.

In MUSE's adversarial training, what does the discriminator try to distinguish?

Mapped source vectors Wx from real target vectors y. The generator is W.

Why is MUSE's generator a single linear matrix rather than a deep network?

A deep generator could match the target distribution while scrambling which word maps where.

What unsupervised criterion does MUSE use to select a checkpoint?

The average cosine between the 10k most frequent source words and their CSLS nearest targets.

Is MUSE a supervised, semi-supervised or unsupervised method?

Unsupervised as a whole; its refinement step is called semi-supervised.

How does fully unsupervised MUSE compare with supervised alignment for distant pairs (English with Russian, Chinese)?

It falls well short.

What is the difference between head-marking and dependent-marking?

Head-marking puts the grammatical marker on the head. Dependent-marking puts it on the dependent.

What is identical-word supervision for crosslingual alignment?

A seed dictionary of words spelled identically in both languages. No human dictionary needed.

Why does unsupervised alignment fail for mixed- and double-marking languages, according to Søgaard et al.?

Each lemma has many distinct surface forms, each its own lower-frequency embedding, so the spaces are non-isomorphic.

How does a domain mismatch between the two corpora affect identical-word supervision and adversarial alignment?

Identical-word supervision degrades but survives. Adversarial alignment collapses to about zero.

How much do hyperparameter changes within one embedding algorithm (window, n-gram range) hurt unsupervised alignment?

Barely.

How is eigenvector similarity Δ computed for two languages?

Sum of squared differences between the largest Laplacian eigenvalues of their nearest-neighbour graphs.

What does a larger eigenvector similarity Δ mean?

The graphs are more structurally different: further from isomorphism.

Why does Finnish give a high eigenvector similarity Δ against English?

One lemma’s inflected forms cluster tightly; English gives a flatter, more evenly connected graph.

True or false: In Skip-gram, the hidden layer is the average of the context word embeddings.

False. That is CBOW. Skip-gram’s hidden layer is the centre word’s embedding.

True or false: CBOW passes its averaged context vector through a non-linear activation before the output layer.

False. CBOW has no non-linearities.

True or false: In Skip-gram with negative sampling, a negative example keeps the input word and replaces the context word with a sampled word.

True. Each of the k negatives pairs the same input word with a word from the noise distribution.

True or false: Word2Vec's context size and number of negative samples can be smaller the more training data there is.

True. More data allows a smaller context and a smaller negative set.

True or false: Raising the unigram distribution to the power 0.75 biases negative sampling towards frequent words.

False. It biases sampling towards rarer words.

True or false: GloVe builds its co-occurrence matrix in a single pass over the corpus.

True. Training then uses only the matrix.

True or false: GloVe's weighting function gives very frequent pairs a lower weight than medium-frequency pairs.

False. It never decreases; frequent pairs get the cap, 1.

True or false: In fastText, only the centre word is split into character n-grams.

True. Context vectors stay per word.

True or false: fastText can produce a vector for a word that never occurred in training.

True. It sums the word’s character n-gram vectors.

True or false: The shared space hypothesis says the two embedding spaces differ only by a rotation.

False. It says a general linear map aligns them; orthogonality is Xing et al.’s added constraint.

True or false: Semi-supervised alignment starts from a seed dictionary of thousands of translations.

False. It starts from hundreds; thousands is the supervised setting.

True or false: For unit-length vectors and an orthogonal W, minimising Euclidean distance is equivalent to maximising cosine similarity.

True. ∥Wx−y∥2=2−2cos(Wx,y).

True or false: An orthogonal mapping can rotate, reflect and scale the source space.

False. No scaling: only rotations and reflections.

True or false: The unconstrained least-squares mapping continuously improves as the embedding dimension grows.

False. It gets worse as the dimension grows.

True or false: MUSE's generator is a deep non-linear network, as in a standard GAN.

False. It is a single linear d×d matrix, deliberately.

True or false: In MUSE, the discriminator only sees vectors of the 50k most frequent words of each language.

True. Rare words’ embeddings are poorly estimated.

True or false: Fully unsupervised MUSE can match supervised alignment for English-Spanish.

True. It matches or slightly beats supervised Procrustes with CSLS on close pairs.

True or false: English-Finnish unsupervised alignment fails because the Finnish corpus is too small.

False. It stays at zero with a much larger Finnish corpus.

True or false: Estonian-Finnish aligns adversarially although neither language aligns with English.

True. Structurally similar languages can align.

True or false: Søgaard et al. found that adversarial alignment fails for mixed- and double-marking languages (Estonian, Finnish, Greek).

True. English-Estonian, -Finnish and -Greek give essentially zero.

True or false: Unsupervised alignment fails when Spanish uses fastText CBOW and English fastText Skip-gram, even with otherwise identical settings.

True. Different base models give about zero.

True or false: In Søgaard et al.'s language comparison, identical-word supervision beats adversarial alignment on every pair involving English.

True. From a small margin (English-Spanish) to working against not working (English-Estonian).

True or false: A rotation of one embedding space cannot change the eigenvector similarity Δ.

True. A rotation keeps the nearest-neighbour graph, so the eigenvalues.

True or false: A low eigenvector similarity Δ proves that two embedding spaces are near-isomorphic.

False. Near-isomorphic spaces give a low Δ, but not the other way round.

Multiple selection: which are true of negative sampling in Word2Vec? (A) It turns prediction into classifying real against noise pairs (B) Each observed pair gets k negatives, typically 5 to 20 (C) It still normalises over the whole vocabulary for each example (D) Negatives are drawn uniformly from the vocabulary

A and B. C: the cost drops to k+1 dot products. D: negatives come from P(w)0.75.

Multiple selection: which are true of GloVe? (A) It fits dot products plus biases to log co-occurrence counts (B) Its weighting function caps at 1 for frequent pairs (C) It treats each context window as an independent event (D) Its final embedding sums the word and context vectors

A, B and D. C: that is the Word2Vec weakness GloVe addresses.

Multiple selection: which are true of fastText? (A) A word's vector is the sum of its character n-gram vectors and the word itself (B) Context vectors are also built from n-grams (C) Its analogy gains over Word2Vec are on syntactic analogies (D) It returns a table of n-gram vectors

A, C and D. B: only the centre word is decomposed.

Multiple selection: which are true of hubness and CSLS? (A) Hubness worsens as dimensionality increases (B) CSLS penalises candidates that are close to many mapped source vectors (C) CSLS requires extensive hyperparameter tuning (D) Nearest-neighbour retrieval is symmetric

A and B. C: only K. D: a hub can be cat’s nearest neighbour without cat being the hub’s.

Multiple selection: which are true of MUSE? (A) The discriminator and the mapping are trained in alternation, each with the other frozen (B) The mapping is kept near-orthogonal after each step (C) The adversarial loss is used to pick the final checkpoint (D) Refinement re-solves the mapping by SVD on mutual nearest neighbours

A, B and D. C: the checkpoint is picked by average CSLS-neighbour cosine.

L06 Contextual Embeddings

Flashcards

What is the shared flaw of static word embeddings, however they are trained?

One vector per word type: train (vehicle), train (to practise) and train of thought all get the same vector.

What trade-off must a contextual word representation strike?

Enough context to separate occurrences of the same word, but not so much that the word’s own contribution becomes unclear.

Name the three strategies for balancing word and context information in contextual representations.

Choosing the right layer(s), choosing the right task(s), tightening connections between layers (e.g. residual connections).

What is the difference between using a pre-trained encoder as a feature extractor and full fine-tuning?

Feature extractor: encoder frozen, only the task head trained. Full fine-tuning: head and encoder updated (BERT’s default).

Which Transformer family is BERT?

Encoder-only: it predicts its own input after masking noise.

Which Transformer family are all current LLMs?

Decoder-only: classical next-word prediction.

What fraction of tokens does BERT select for masked language modelling?

15%.

In BERT pre-training, what happens to a token selected for masking?

80% replaced by [MASK], 10% by a random word, the rest left unchanged.

How are BERT's next sentence prediction pairs built?

50% B truly follows A (IsNext), 50% B is a random segment (NotNext).

Which BERT special token is never masked and has a final output representing the whole input sequence?

[CLS].

When fine-tuning BERT, where does the task head attach for classification versus tagging?

Classification: the [CLS] output C. Tagging and span extraction: the token outputs Ti​.

Which new parameters does BERT learn when fine-tuned for SQuAD?

Only a start vector S and an end vector E, scored against each token output by inner product.

What is the difference between BPE's and WordPiece's merge criterion?

BPE merges the most frequent pair; WordPiece the pair with the highest count(a,b) / (count(a) · count(b)).

What does WordPiece do with a word containing a character missing from its vocabulary?

The whole word becomes [UNK], where BPE and Unigram LM fall back to characters.

Why does per-token random masking weaken MLM when words are split into subwords?

Morphological pieces (suffixes) are trivially recoverable from the visible stem, so many masked positions teach little.

Which masking scheme masks all subword pieces of a word together, at an unchanged masking rate?

Whole-word masking.

Which cross-lingual signals does mBERT's training lack?

Parallel data, language-ID embedding, language-specific parameters, alignment loss.

What goes wrong with language sampling at α = 0?

Sampling becomes uniform: tiny languages are oversampled so much that the model memorises them.

Why does mBERT have more parameters than BERT-base?

Entirely the bigger vocabulary (embedding matrix); the architecture is identical.

Even with smoothing, which languages does mBERT's shared vocabulary favour?

High-resource languages and Latin script.

Which languages get high fertility under mBERT's shared vocabulary?

Low-resource and morphologically rich languages: many more pieces per word.

Why is uncased mBERT bad for some languages?

It lowercases and strips accents, damaging languages that depend on diacritics.

What is zero-shot cross-lingual transfer?

Fine-tune on task data in language A only, evaluate on language B with no task data in B.

Does mBERT transfer between languages with different scripts, such as Hindi and Urdu?

Yes, well, despite almost no shared wordpieces.

What does mBERT's flat zero-shot F1 against wordpiece overlap imply?

Its transfer is not surface string matching: representations are shared below the level of surface wordpieces.

From an SVO fine-tuning language, how does mBERT's zero-shot POS transfer to SVO targets compare with SOV targets?

SVO targets are far better than SOV (verb-final) targets.

Which typological database records structural features of languages and is used in NLP to measure structural similarity?

WALS (World Atlas of Language Structures).

How does zero-shot POS accuracy change as two languages share more WALS features?

It rises, for both mBERT and English BERT (mBERT higher throughout).

In mBERT translation retrieval, how is an English sentence "translated" before the nearest-neighbour search?

Shifted by one average EN-to-DE difference vector, then matched by ℓ2​ distance.

What happens to mBERT zero-shot transfer if layers up to 9 are frozen during fine-tuning?

It hurts NER (most), POS and XNLI, though not MLDoc: the upper layers must adapt to the task.

For which task does wordpiece overlap with English correlate most strongly with mBERT's zero-shot score?

NER, almost perfectly: the most lexical task, with entities often copied verbatim.

For which task does wordpiece overlap with English show no correlation with mBERT's zero-shot score?

XNLI (sentence-level inference).

What is fake English (K et al. 2020)?

English with every Unicode codepoint shifted by a large constant, so it shares no characters with the other language.

Which model-architecture factor has the largest impact on B-BERT's cross-lingual transfer?

Depth.

What does the mixed-language XNLI drop (premise and hypothesis in different languages) show about mBERT-style models?

The space is not truly language-neutral: good at a task in another language, poor at relating two languages in one input.

What is the difference between "within" and "across" in Rajaee and Monz's XNLI evaluation?

Within: premise and hypothesis in the same language. Across: in different languages.

What is the heuristics hypothesis (Rajaee and Monz)?

Transfer of heuristics can contribute to cross-lingual generalisation.

Which shortcut does SNLI training data offer an NLI model?

Full premise-hypothesis word overlap almost always means entailment; low overlap mostly non-entailment.

Why does XLM-R drop next sentence prediction and train with MLM only?

NSP contributes little and sometimes hurts performance.

What is the difference between static and dynamic masking?

Static: masked once in preprocessing, reused every epoch. Dynamic: a fresh mask each time a sequence is fed.

What data is XLM-R trained on?

CC-100: filtered CommonCrawl in 100 languages, two orders of magnitude more than mBERT’s Wikipedia.

What vocabulary does XLM-R use?

250k entries, Unigram LM via SentencePiece: better fertility, bigger embedding matrix.

True or false: BERT's MLM loss is computed only at positions that show the [MASK] token.

False. It covers all selected positions, including those given a random or unchanged word.

True or false: Whole-word masking keeps the overall masking rate unchanged.

True. Still about 15% of tokens; only the choice of which tokens changes.

True or false: WordPiece inference replays the learned merges in order, like BPE.

False. It uses greedy longest match against the final vocabulary.

True or false: mBERT was trained with a small amount of parallel data to align its languages.

False. mBERT uses no parallel data and no alignment loss.

True or false: Raising the sampling temperature T moves language sampling closer to proportional sampling.

False. A higher temperature moves it closer to uniform.

True or false: English BERT's zero-shot NER F1 is roughly flat in entity-wordpiece overlap.

False. That is mBERT; English BERT’s F1 rises with overlap.

True or false: Permuting words during pre-training hurts cross-lingual transfer significantly but does not eliminate it.

True. Accuracy drops, but stays well over chance.

True or false: In mBERT translation retrieval, accuracy peaks in the middle layers.

True. It follows an inverted U: middle layers are the most language-neutral, top layers language-specific again.

True or false: Freezing mBERT's lower layers during English fine-tuning helps or is neutral for zero-shot transfer.

True. Frozen lower layers keep their multilingual representation.

Multiple selection: which are true of mBERT's training? (A) It uses the same loss as BERT, MLM plus NSP (B) NSP pairs may mix two languages (C) It has a language-ID embedding (D) All languages share one subword vocabulary

A and D. B: NSP pairs are always in one language. C: there is no language-ID embedding.

Multiple selection: which are true of language sampling with pl​∝nlα​? (A) α = 1 samples in proportion to data size (B) α = 0 samples uniformly (C) α = 0.7 down-weights low-resource languages (D) mBERT also smooths the counts used to build its vocabulary

A, B and D. C: α = 0.7 up-weights low-resource languages.

Multiple selection: which are true of what drives mBERT-style transfer? (A) Removing all subword overlap eliminates most transfer (B) Permuting words in pre-training reduces transfer without eliminating it (C) Deeper models narrow the in-language to zero-shot gap (D) A single factor explains transfer

B and C. A: removing all overlap barely changes transfer. D: no single factor explains it.

Multiple selection: which are true of XLM-R compared with mBERT? (A) It drops next sentence prediction (B) It uses static masking (C) It has a larger vocabulary (D) Its average within-language score beats mBERT's on both XNLI and QA

A, C and D. B: XLM-R uses dynamic masking.

Multiple selection: which are true when premise and hypothesis (or question and context) are in different languages? (A) B-BERT accuracy falls under both monolingual conditions (B) mBERT's across score exceeds its within score (C) XLM-R's average across-language QA score beats mBERT's (D) For mBERT an English hypothesis is easier than an English premise

A and D. B: across is lower than within. C: XLM-R’s average across QA score is lower than mBERT’s.

L07 Crosslingual NLP

Flashcards

What is crosslingual knowledge transfer?

Fine-tuning on task data in language A, then testing on the same task in language B.

Why does training on many languages not by itself link them?

Predicting word W in language L gains nothing from unrelated L′ context: languages share parameters, never context.

What is the difference between parallel and comparable data?

Parallel: meaning-equivalent pairs (translations). Comparable: same topic, parallel only to a degree on a sliding scale.

What are the two steps of crawling your own parallel corpus?

Document alignment, then sentence alignment inside the aligned documents.

What data is LASER trained on?

Parallel data: it is an encoder-decoder trained to translate.

Which sentence alignment method matches sentences by LASER embedding similarity, with a search that scales to massive data sets?

vecalign.

What does XLM add that mBERT lacks?

An explicit crosslingual loss on parallel data. mBERT never sees a translation pair, so its alignment is an emergent side effect.

What are XLM's three pretraining objectives?

CLM, MLM, TLM.

Why does TLM force crosslingual alignment?

A masked word can be predicted from its unmasked translation in the other language, so the model learns to attend across languages.

What are InfoXLM's three objectives?

MMLM, TLM, XLCo.

What is the difference between the crosslingual signal of TLM and of XLCo?

TLM aligns at the token level; XLCo aligns whole-sentence representations.

What is the difference between the within and across scores in mixed-language XNLI and QA?

Within: both input parts in language ℓ. Across: mean over mixed-language combinations with ℓ in either part.

What do mixed-language evaluations show about crosslingual ability without a crosslingual training signal?

They cast doubt on it: zero-shot results seemed to show it, but mixed-language tasks show large drops.

What two assumptions of sequence labelling does sequence-to-sequence modelling drop?

That xt​ corresponds to yt​, and that ∣X∣=∣Y∣.

How is sequence-to-sequence modelling written as conditional language modelling?

p(yt​∣Y<t​,X): the next output token given the decoder prefix and the encoder output.

Which four complex mappings make machine translation hard?

Different lengths, word order differences, one-to-many, many-to-one.

What problem does h0dec​=hnenc​ cause in an RNN encoder-decoder?

An information bottleneck: the whole source sentence must pass through one fixed-size vector.

How do the NMT decoder input x and the target y differ?

x = <s> + sentence, y = sentence + </s>: the same sentence shifted by one.

With small parallel corpora, which wins: NMT or statistical MT?

Statistical MT. NMT is data hungry: it starts far lower and only overtakes with much more data.

What is parent-child transfer learning for NMT?

Train on a high-resource pair (parent), then continue training the same model on the low-resource pair (child).

Which conditions make parent-child NMT transfer work best?

Same target language, related source languages, frozen decoder (in the experiments only the target embeddings), shared vocabulary.

Does a related parent help NMT transfer more than an unrelated one in Zoph et al. (2016)?

Yes: a Spanish child gains more from a French parent than from a German one.

What is the difference between parent-child transfer and multilingual NMT?

Parent-child transfers knowledge in stages; multilingual NMT transfers it in parallel through joint training.

What is translating in a language direction never seen during training called?

Zero-shot translation.

What are the two indicators that knowledge transfer happens in multilingual NMT?

Performance on zero-shot directions, and beating a bilingual baseline trained only on that direction’s data.

What is it called when a direction gets worse because other languages compete for the same model capacity?

Interference.

Which sampling temperature gives proportional sampling?

T=1.

How does zero-shot translation compare with supervised directions?

It still lags behind.

Besides the number of training languages, what does zero-shot translation quality depend on?

Which languages are included: related pairs (Belarusian→Russian) do far better.

What is BART's pretraining task?

Reconstruct the original document from a corrupted one: a denoising autoencoder.

What are BART's five noise functions?

Token masking, token deletion, text infilling, sentence permutation, document rotation.

What extra thing must BART work out under text infilling?

How many tokens the single [MASK] stands for.

How is BART fine-tuned for classification?

The same input goes to encoder and decoder; the label is predicted from the last decoder hidden state.

How is BART adapted for machine translation into English?

A randomly initialised source encoder replaces the embedding layer of BART’s encoder.

What is the difference between Fixed BART and Tuned BART for Romanian→English MT?

Fixed (BART frozen) is worse than the baseline; Tuned (BART updated) beats it.

Which noise functions does mBART's pretraining use?

Text infilling plus sentence permutation.

At what amount of parallel data does mBART pretraining help translation most?

Low to medium (a few hundred thousand pairs). Almost no data cannot be rescued, and gains shrink with more data.

Why does InfoXLM have no language embeddings, unlike XLM?

It keeps XLM-R’s architecture so it can keep XLM-R’s weights.

On mixed-language XNLI, is XLM-R better or worse than mBERT across languages?

Better. Only on mixed-language QA does XLM-R fall below mBERT.

True or false: TLM uses a different loss function from MLM.

False. The loss is the same; only the input (a sentence plus its translation) differs.

True or false: In TLM, the position embeddings restart at 0 for the second sentence.

True. So position cannot tell the halves apart; language embeddings mark them instead.

True or false: LASER's decoder is told the output language by a language ID embedding, not by the encoder.

True. So the sentence vector has no reason to encode the input language.

True or false: InfoXLM is only slightly better than XLM-R within a language but much better across languages.

True. The explicit crosslingual objectives mainly close the within-across gap.

True or false: In the Transformer encoder-decoder, every decoder layer can attend to all encoder output positions.

True. The source-target context layer does this, removing the RNN’s single-vector bottleneck.

True or false: With a shared vocabulary, an unrelated parent can help an English→Estonian NMT child about as much as a related Finnish parent.

True. Kocmi and Bojar: Czech and Russian parents help as much as Finnish.

True or false: Transferring only a parent's embeddings, without its inner layers, beats training the NMT child from scratch.

False. Embeddings alone are worse than scratch on average; the inner layers carry the benefit (Aji et al.).

True or false: mBART pretraining makes translation work even with almost no parallel data (around 10K pairs).

False. With 10K pairs (English-Gujarati) BLEU stays near zero; pretraining cannot rescue almost no data.

True or false: Adding more languages to a multilingual NMT model always improves zero-shot translation.

False. Most zero-shot directions improve, but not all (Fr→Zh got worse).

True or false: LASER's sentence embedding is obtained by max pooling over the BiLSTM states.

True. Max pooling gives one fixed-size vector, whatever the sentence length.

True or false: Many-to-one multilingual NMT beat the bilingual baselines in every direction in Johnson et al. (2017).

True. By small margins; one-to-many was mixed.

True or false: XLM-R is better than mBERT across languages on mixed-language QA.

False. It is better within languages but, on average, worse across them on QA.

True or false: BART's decoder is bidirectional.

False. The encoder is bidirectional; the decoder is autoregressive.

True or false: Transfer learning for NMT works best if decoder parameters are frozen.

True. It is in Monz’s list of conditions; the freezing experiment narrows it to the target embeddings.

True or false: InfoXLM's MMLM uses negative sampling.

True. Instead of directly optimising the loss of the ground truth.

True or false: In multilingual NMT, many-to-many translation is used for testing only.

True. Training is English-centric, so non-English pairs are zero-shot.

Multiple selection: which are true of multilingual NMT as in Johnson et al. (2017)? (A) Each language gets its own encoder. (B) A tag naming the target language is added to the source sentence. (C) Source, target and output embeddings are shared. (D) Training uses every language pair, including pairs without English.

B and C. (A) false: all parameters are shared across languages. (D) false: training is English-centric (xx→en, en→xx); non-English pairs are zero-shot.

Multiple selection: which are true of language sampling in multilingual NMT? (A) Proportional sampling lets high-resource languages dominate. (B) Uniform sampling hurts low-resource languages. (C) A temperature of T = 100 approximates uniform sampling. (D) The best compromise over-samples low-resource languages.

A, C and D. (B) false: uniform sampling hurts high-resource languages; low-resource ones can do well under it.

Multiple selection: which are true of Arivazhagan et al.'s (2019) 103-language NMT results? (A) Low-resource languages gain most when translating into English. (B) Multilingual models beat bilingual baselines on high-resource languages. (C) All→All is weaker than the dedicated Any→En and En→Any models. (D) One-to-many gains more than many-to-one for low-resource languages.

A and C. (B) false: no multilingual model beats the bilingual baselines on the high-resource group (interference). (D) false: low-resource gains are far larger into English.

Multiple selection: which are true of mBART? (A) It is pretrained on parallel data. (B) Its pretraining objective has no crosslingual signal. (C) A language ID token starts the decoder input. (D) Translation fine-tuning requires a new randomly initialised source encoder.

B and C. (A) false: it is pretrained on concatenated monolingual data. (D) false: that is how English-only BART is used; mBART is fine-tuned as is.

Multiple selection: which are true of parent-child transfer learning for low-resource NMT? (A) The child model is initialised with the parent's parameters. (B) The target-language embeddings stay frozen during child training. (C) The source embeddings stay frozen during child training. (D) Transfer from a smaller parent to a larger child works as well as the reverse.

A and B. (C) false: the source embeddings must be retrained. (D) false: reversed transfer helps little or hurts.

Multiple selection: which are true of XLM and InfoXLM pretraining? (A) XLM keeps BERT's next sentence prediction. (B) XLM's TLM is always combined with MLM or CLM. (C) InfoXLM's XLCo classifies whether a sentence pair is parallel from [CLS] representations. (D) InfoXLM is trained from scratch.

B and C. (A) false: XLM drops NSP. (D) false: InfoXLM is initialised from XLM-R.

Multiple selection: fine-tuning adapts a general-domain NMT system to a small in-domain set (possibly another language pair). Which are true? (A) It uses the general-domain parameters for initialisation. (B) It continuously improves with the number of in-domain updates. (C) It does not suffer from catastrophic forgetting.

A only. (B) false: with little data, quality peaks and then drops. (C) false: training only on in-domain data overwrites general-domain knowledge.

Multiple selection: which are true of BART's noise functions? (A) Text infilling replaces a span with a single [MASK]. (B) Token deletion marks each deleted position with [MASK]. (C) Sentence permutation alone performs poorly. (D) Text infilling is the best single noise function.

A, C and D. (B) false: deletion leaves no mark, so the model must find where tokens are missing.
