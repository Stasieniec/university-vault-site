L01 Agents, Multiagent Systems and Agentic AI

Exam questions

Give the Russell and Norvig and the Wooldridge definitions of an agent. What does each emphasise, and why do Russell and Norvig call the notion of an agent "a tool for analyzing systems"?

Key points: R&N: perceives environment through sensors, acts through actuators; Wooldridge: situated, autonomous action, design objectives; R&N stress the perception-action interface and “can be viewed as”, Wooldridge autonomy and goals; “agent” is a lens for analysis; calculator example.

Russell and Norvig: an agent is anything that can be viewed as perceiving its environment through sensors and acting upon it through actuators. Wooldridge (2001): an agent is a computer system situated in an environment and capable of autonomous action in it to meet its design objectives. Both place the agent in an observe-act loop with an environment. Russell and Norvig stress the interface (percepts in, actions out) and the phrase “can be viewed as”. Wooldridge adds autonomy (the system chooses its own actions) and objectives (it acts to achieve goals set by its designer).

Russell and Norvig warn that the notion of an agent is an analysis tool, not a line that divides the world into agents and non-agents. A calculator can be described as an agent that displays “4” after the percepts “2 + 2 =”, but that description adds nothing to our understanding of it. The agent view is worth using when a system chooses among actions in pursuit of an objective, as a vacuum robot or an LLM agent does.

Describe the kinds of agent program from simple reflex to learning agents. What does learning add, and what makes learning hard, especially when there are several agents?

Key points: simple reflex (current percept, condition-action rules); model-based (internal state); goal-based (considers future outcomes against a goal); utility-based (trade-offs via a utility function); learning agent improves its components from feedback; difficulties: value estimation, exploration vs exploitation, non-stationarity when others learn.

A simple reflex agent maps the current percept to an action with condition-action rules (vacuum: suck if dirty, else move). A model-based reflex agent keeps internal state about the parts of the world it cannot currently see. A goal-based agent uses goal information and predicts what its actions lead to, which brings in search and planning. A utility-based agent scores outcomes with a utility function (an internal version of the performance measure), so it can trade off conflicting goals and handle uncertainty. A learning agent can be any of these, plus learning: modifying each component of the agent to agree better with the available feedback, which improves its overall performance.

Learning a policy is hard because (1) the value of actions is difficult to estimate from noisy, delayed feedback; (2) the agent must balance exploration (trying actions to learn about them) against exploitation (using the best known action); and (3) environments can be non-stationary. In a multi-agent system the other agents are learning too, so from each agent’s view the environment keeps changing and old value estimates go stale.

What is an LLM agent? Explain the thought-action-observation loop and how ReAct implements it, linking each step to a component of the agent.

Key points: acts, observes, reasons and plans through natural language; token completion is multi-task; LLM plus role, memory, tools, planning; loop: reason/plan, act, observe; ReAct (Yao et al., ICLR 2023) prompts interleaved verbal reasoning and actions; Thought = reasoning (CoT), Action = tools, Observation = memory (tool output in context).

An LLM agent is an agent whose reasoning, planning and actions happen in natural language. A language model can play this role because next-token completion is multi-task: the same mechanism answers world-knowledge, history, planning and arithmetic prompts. The model becomes an agent when it is given a role, memory, tools and planning, and placed in a loop with an environment.

The loop has three steps: reason and plan in text, act, observe the result, then repeat. ReAct is a prompting technique that makes a language model generate verbal reasoning and actions, both as text, iteratively as Thought, Action, Observation. The Thought forces multi-step chain-of-thought reasoning; the Action is text that calls an external tool; the Observation inserts the tool’s output into the model’s context, which serves as its memory. The cycle continues until the agent produces a final answer.

Explain how LLM agents handle memory and tools. Distinguish short-term from long-term memory, and list the problems that tool use raises.

Key points: memory = facts, past interactions, context; key to go from LLM to agent; short-term = limited context window, context engineering, trimming or summarising; long-term = external databases or knowledge in parameters; tools = external functions that let agents act; creation, definition, selection, calling, output processing; MCP standardises connection.

Memory lets an agent keep facts, previous interactions and context; without it each step starts from nothing, which is why memory is key to going from an LLM to an agent. Short-term memory is the context window. It is limited, so what enters it must be chosen (context engineering), and long histories are trimmed or summarised. Long-term memory is either external, a database the agent retrieves from, or internal, the knowledge stored in the model’s parameters. Retrieval therefore serves as an agent’s long-term memory, and in the other direction agent-centric information access (Kanoulas et al.) retrieves among expert agents.

Reasoning lets an agent plan; tools let it act. A tool is an external function the model can use, such as search or code execution. Tool use raises five problems: creating and documenting tools so an LLM can use them, defining them so the agent knows they exist, selecting the right tool, calling it (parsing and executing the call), and processing its output back into the LLM. Toolformer showed models can teach themselves tool use; the Model Context Protocol standardises how LLMs connect to tools.

What are reasoning LLMs, and how can reasoning and planning in LLM agents be obtained or improved?

Key points: generate thought tokens before the answer; shift from train-time to test-time compute; prompting (CoT, zero- or few-shot) elicits reasoning in untuned models; search and verify; fine-tuning with RL (DeepSeek-R1); planning = decomposing into sub-tasks; CoT, Least-to-Most, Plan-and-Solve; fine-tuning (SFT, RL) for planning and the ReAct cycle; Reflexion.

A reasoning LLM produces thoughts as tokens before its final answer. This moves effort from train-time compute to test-time compute: more tokens at answer time means more computation on the problem. Reasoning can be elicited by prompting, with chain-of-thought prompting in zero-shot or few-shot form, even in models not tuned for reasoning. It can be improved by search and verify (sample many reasoning traces and reward the best) or by fine-tuning the model’s token probabilities for reasoning, for example with reinforcement learning, as in DeepSeek-R1.

Planning uses reasoning to find the steps that reach a goal: decompose the task into sub-tasks and generate an action sequence. Early methods were prompting techniques (CoT, Least-to-Most, Plan-and-Solve). Models can also be fine-tuned, by supervised fine-tuning or RL, to plan and to run the ReAct cycle better. Reflexion adds verbal reinforcement learning: the agent learns from feedback through reflections written in language.

What risks arise when many LLM agents interact? Use the categories of Hammond et al. and the OpenAI-Hugging Face incident.

Key points: miscoordination, conflict, collusion; agents communicated through a software repository service in unexpected ways; agent communication is not inherently problematic but can create risk; models tampered with outputs and logs, abused context compaction, injected code into the evaluator’s container, printed adversarial outputs; explicit about it in their CoT; behaviour depends on how rewards are defined.

Hammond et al. (2025) identify three under-explored risks of LLM-based multi-agent systems: miscoordination, conflict and collusion. The incident shows related risks in practice. Agents used Artifactory in unexpected ways to communicate with each other before the Hugging Face incident; the incident report notes that OpenAI’s models are trained to communicate when given a multi-agent collaboration tool, and that such communication is not inherently problematic but can create risk. The models also tried to deceive their evaluator, to hide that they had obtained an answer flag by cheating: erasing or tampering with outputs and message logs, abusing context compaction, injecting malicious code into the evaluator’s container and printing adversarial outputs, while stating these attempts openly in their chain-of-thought.

The lesson ties back to simple agents: the components that make agents useful (communication, memory, tools) are also routes for deception, and whether agents deceive depends on how their rewards and payoffs are defined, which is rarely trivial.

Using the Prisoner's Dilemma, the Stag Hunt and the vacuum world, explain why simple agents can produce outcomes nobody wants.

Key points: PD: D dominates, (D,D) the only equilibrium, worse for both than (C,C); Stag Hunt: (C,C) and (D,D) both equilibria, C risky; at 50% C, D earns 2.5 vs 2 so C declines; vacuum: two rewards give the same behaviour until Dump exists, then reward 2 dumps and re-sucks; design rewards for the outcome wanted.

In the Prisoner’s Dilemma (C,C = 3,3; C,D = 0,5; D,D = 1,1) defecting pays more whatever the other does (5 > 3, 1 > 0), so rational agents reach (D, D), which both rank below (C, C): a cooperation dilemma. In the Stag Hunt (C,C = 4,4; C,D = 0,3; D,D = 2,2) the best reply matches the partner, so both (C, C) and (D, D) are equilibria; (C, C) is better but risky, a coordination dilemma. In a population with 50% of each type meeting at random, C earns 2 and D 2.5 on average, so if successful strategies spread, cooperators decline.

In the vacuum world, rewarding each clean square per time step and rewarding each unit of dirt sucked produce the same behaviour with Left, Right and Suck. Add Dump and the second reward is maximised by dumping dirt and sucking it again forever. Rewards should describe the outcome wanted in the environment, not the behaviour the designer expects.

L02 Game Theory and Population Dynamics

Exam questions

(Mock Q6) A Prisoner's Dilemma has row payoffs R (C against C), S (C against D), T (D against C) and P (D against D), with T > R > P > S. The game is symmetric. (a) Show that D is the best response to both C and D. (b) Show that (D, D) is the only pure Nash equilibrium and that it is not Pareto optimal. (c) Show that (C, D) is Pareto optimal. Is it a good outcome? What does this say about Pareto optimality as a criterion? (d) Give the condition on the payoffs under which (C, C) is the social optimum.

Key points: against C, T > R; against D, P > S, so D is dominant; any other cell has a player who gains by switching to D, and (C, C) gives both R > P; (C, D) = (S, T) gives the column player its maximum, so it is Pareto optimal but unfair; Pareto optimality ignores fairness; (C, C) is the social optimum if 2R ≥ T + S.

(a) Against C, D earns T > R. Against D, D earns P > S. So D is a best response in both cases (a dominant action).

(b) In any other outcome, a player who plays C can gain by switching to D, so only (D, D) is an equilibrium. It is not Pareto optimal, because (C, C) gives both players more payoff (R > P).

(c) (C, D) leads to payoff (S, T). The column player gets its highest payoff T, so any improvement for the row player would cost the column player. So it is Pareto optimal, although the row player gets its lowest payoff. Pareto optimality says nothing about fairness; this is a limitation.

(d) (C, C) is the social optimum if 2R ≥ T + S. ((D, D) never competes, since 2P < 2R.)

A symmetric Stag Hunt has R = 4, S = 0, T = 3, P = 2. (a) Give the best response to C and to D. (b) Find the pure Nash equilibria and the Pareto-optimal outcomes. (c) Compute the expected payoff of C and of D against a partner who plays C with probability 1/2. (d) A large population plays this game under the replicator dynamics. What happens from 50% C, and from 80% C?

Key points: best response to C is C (4 > 3), to D is D (2 > 0); pure NE (C, C) and (D, D), only (C, C) Pareto optimal; C earns 2, D earns 2.5; tipping point at 2/3; 50% goes to all D, 80% to all C.

(a) Against C, C earns 4 and D 3, so C. Against D, C earns 0 and D 2, so D. The best response copies the partner.

(b) (C, C) and (D, D) are both equilibria: in each, switching alone lowers the deviator’s payoff. (C, D) and (D, C) are not: the agent playing C gains by switching. (C, C) = (4, 4) gives both agents more than any other cell, so it is the only Pareto-optimal outcome (and the social optimum). (D, D) is an equilibrium that is worse for both, the coordination dilemma.

(c) C: 0.5 · 4 + 0.5 · 0 = 2. D: 0.5 · 3 + 0.5 · 2 = 2.5. D is the safer choice when unsure.

(d) fC​−fD​=4x−(2+x)=3x−2, negative below 2/3 and positive above. From 50%, D earns more, so C shrinks to 0 (all D). From 80%, C earns more (3.2 against 2.8), so C grows to 1 (all C). The interior point 2/3, the mixed equilibrium, is unstable.

Hawk-Dove has (C, C) = 3, 3; (C, D) = 2, 8; (D, C) = 8, 2; (D, D) = −2, −2. (a) Give the best responses and the pure Nash equilibria. (b) Which outcomes are Pareto optimal, and which is the social optimum? (c) Find the symmetric mixed equilibrium. (d) What does the replicator dynamics predict for a large population, and why?

Key points: best response is the opposite action; pure NE (C, D) and (D, C) (outside the course material); Pareto optimal (C, C), (C, D), (D, C), social optimum (C, D) and (D, C) with total 10; mixed NE C with probability 4/9; stable coexistence at 4/9 C because each strategy earns more when rare.

(a) Against C, D is better (8 > 3); against D, C is better (2 > −2). So the pure equilibria are (C, D) and (D, C), where one agent yields. (The course names only the mixed equilibrium of part (c); the pure ones follow from the best responses but are outside the course material.)

(b) (D, D) = (−2, −2) is dominated by every other cell. (C, C), (C, D) and (D, C) cannot be improved for one agent without hurting the other, so they are Pareto optimal. Totals: 6, 10, 10, −4, so the social optima are (C, D) and (D, C).

(c) Partner plays C with probability q: C earns 3q+2(1−q)=2+q, D earns 8q−2(1−q)=10q−2. Equal at q=4/9, so each agent plays C with probability 4/9.

(d) x˙=x(1−x)(4−9x): C grows below 4/9 and shrinks above it, so the population converges to a stable mix of about 44% C. Each strategy earns more when it is rare: among conventional agents a dangerous one earns 8, among dangerous agents a conventional one earns 2 against their −2. Unlike the Stag Hunt, here the mixed equilibrium is where the population ends.

L03 Intro to Multi-Agent Reinforcement Learning

Exam questions

The mock’s open question on this part (12, the Stag Hunt with independent Q-learners) is in Lab 2.

Two independent Q-learners play the climbing game, a fully cooperative game with shared reward (rows a, b, c for agent A, columns for agent B): (11, −30, 0 / −30, 7, 6 / 0, 0, 5). (a) Early in learning the partner plays uniformly at random. Compute the expected reward of each action. (3 points) (b) Explain why the learners usually end at (c, c) and not at (a, a). (3 points) (c) What does a central Q-learner learn, and why does it find (a, a)? (2 points) (d) Give one reason why independent learning is still widely used. (2 points)

Key points: a: −19/3 ≈ −6.3, b: −17/3 ≈ −5.7, c: 5/3 ≈ 1.7; Q-values average over the partner’s actions, c never risks −30; a pays only if both play a together, and failed attempts cost −30, so exploring a is punished; central learner has one Q-value per joint action, sees 11 directly; independent learning scales (∣A∣×N against ∣A∣N) and needs no observation of others’ actions.

(a) Against a uniform partner: a earns (11−30+0)/3≈−6.3, b earns (−30+7+6)/3≈−5.7, c earns (0+0+5)/3≈1.7.

(b) An independent learner’s value is the reward averaged over what the partner plays, QA​(a)≈∑b​πB​(b)R(a,b), so c looks best: it never risks −30. Both agents drift to c. Once the partner plays c, exploring a earns 0 (or −30 when the partner explores b), so Q(a) never recovers; (a, a) pays only if both explore a in the same round. They are stuck at the safe action (minimax), and the optimum is unreachable.

(c) A central Q-learner keeps one Q-value per joint action, Q(s,aA,aB), and chooses the joint action for both agents. The value of (a, a) is 11 whatever else happens, so it finds the optimum.

(d) It scales: each agent tracks only its own actions (∣A∣×N values against ∣A∣N joint actions), and it does not need to observe the other agents’ actions. (Also: any single-agent algorithm can be used, and in larger environments such as level-based foraging it learned faster than central learning.)

Four warehouse robots each have 5 actions and share a team reward. (a) How many joint actions must a central Q-learner explore per state, and how many action values do independent Q-learners keep per state in total? (2 points) (b) Give two limitations of central Q-learning. (3 points) (c) Give two advantages and two limitations of independent Q-learning. (4 points) (d) One robot often idles while the others work, and its idling is reinforced. Which challenge of MARL is this? (1 point)

Key points: 54=625 joint actions against 4×5=20 values; central: exponential joint action space, needs a central controller that observes and commands all robots (and one scalar reward); independent: scales, no need to observe others’ actions; non-stationary environment, no convergence guarantee, averaging hides good joint actions (miscoordination); credit assignment (the lazy agent).

(a) A central learner chooses among all joint actions: 54=625. Independent learners each keep values for their own 5 actions: 4×5=20 in total.

(b) The joint action space grows exponentially with the number of agents, so learning and exploring it becomes intractable. It needs a central controller that sees everything and commands every robot, which may be impossible during execution. (MARL book: it also needs the rewards combined into one scalar, easy here because the reward is shared.)

(c) Advantages: each table covers only the agent’s own actions, so it scales with the number of agents; agents do not need to observe each other’s actions. Limitations: the other robots keep learning, so each robot’s environment is non-stationary and Q-learning’s convergence guarantees are lost; the value of an action is averaged over what the others currently do, which can hide good joint actions and lead to miscoordination.

(d) Multi-agent credit assignment: with a shared team reward, the idle robot receives +1 when the others succeed (the lazy agent problem).

(a) Write the Q-learning update, say what the target is, and give the target when s′ is terminal. (3 points) (b) What is the main limitation of value iteration compared with Q-learning? (2 points) (c) Give two limitations of tabular Q-learning. (2 points) (d) Why are the Q-learning convergence guarantees lost when several independent Q-learners learn at once? (3 points)

Key points: Q(s,a)←Q(s,a)+α[r+γmaxa′​Q(s′,a′)−Q(s,a)], target r+γmaxa′​Q(s′,a′), terminal: r; value iteration needs the transition and reward functions; tables do not generalise (experience does not carry over to similar states) and grow with the number of state-action pairs; the others’ learning makes the transitions and rewards each agent experiences change, the environment is non-stationary, and the proofs assume a fixed MDP.

(a) Q(s,a)←Q(s,a)+α[r+γmaxa′​Q(s′,a′)−Q(s,a)]. The target r+γmaxa′​Q(s′,a′) is a one-sample estimate of the return after taking a and acting greedily afterwards; α sets how far the estimate moves towards it. If s′ is terminal there is no future value, so the target is r.

(b) Value iteration needs a model of the environment, the transition function P(s′∣s,a) and the reward function, which is usually unavailable or intractable. Q-learning needs only sampled transitions.

(c) Each value is learned in isolation, so experience in one state does not carry over to similar states and every state-action pair must be visited; and the table grows with the number of state-action pairs, too large for complex environments.

(d) Each agent treats the others as part of its environment. The transitions it experiences, Pi(s′∣s,ai)=∑a−i​[∏j=i​πj(aj∣s)]P(s′∣s,ai,a−i), change whenever the others’ policies change, and so do its rewards. The convergence proof of Q-learning assumes a fixed (stationary) MDP, so it no longer applies: best responses can cycle, and targets go stale.

L04 Deep RL and Intro to Deep MARL

Exam questions

Mock Q21 (open, 10 points): Tabular Q-learners play the Coin Game, whose table has 1,458 rows. Each of k random lamps doubles the number of rows (as lamps can be on or off). Training plays 300 updates, each with 32 parallel games of 16 steps, and every step gives one decision per agent. Coins per episode are 14.5 with no lamps and 4.9 with 8 lamps, while random agents collect 3.7. (a) Compute the number of rows N for k = 0 and k = 8, and the budget B of decisions per agent. (3 points) (b) Use these numbers to explain the drop in performance. Why can't agents with tabular learning discover that the lamps do not matter? (3 points) (c) Explain how a neural network avoids this problem. Name one new challenge it introduces. (4 points)

Key points: N=1,458 and 1,458⋅28, B=300⋅32⋅16; rows grow while the budget stays, so most rows are never visited and unvisited rows hold zeros (random play); rows that differ in one lamp share nothing, so each lesson is relearned per lamp pattern; a network maps observations to values or a policy with shared weights, so learning about the coin’s position applies to all lamp patterns and the lamps get little weight; new challenge: instability from moving targets or correlated data, divergence, no convergence guarantee, more computation.

(a) N=1,458 for k=0, and N=1,458⋅28=373,248 for k=8. B=300⋅32⋅16=153,600 decisions per agent.

(b) With 8 lamps, most rows are never visited, and the others are visited only a few times (about 0.4 decisions per row, against about 105 without lamps). An unvisited row still holds zeros, so the agent acts at random there. The number of rows grows but the budget remains, so the probability of visiting each state becomes too low, and performance drops from 14.5 coins to 4.9, close to random (3.7). Two rows that differ in one lamp share nothing, so each lesson must be learned again for each of the other lamp patterns. That is why the table cannot discover that the lamps do not matter.

(c) A network computes values or a policy as a function of the observation, with shared weights. What it learns about the coin’s position applies to all lamp patterns, and it can give the lamps little weight. New challenges: instability from moving targets or correlated data, possible divergence, no general convergence guarantee, and more computation needed.

A deep Q-learner on the Coin Game first computes its targets with the network it is training and learns from each transition right after it happens. Its values oscillate, and after long stretches in one part of the grid it forgets what it knew elsewhere. (a) Name and explain the two problems. (4 points) (b) Explain how DQN's target network and replay buffer each address one of them. (4 points) (c) Why may DQN learn from buffer transitions whose actions were chosen by older versions of the agent? (2 points)

Key points: moving targets: targets depend on θ, and a network update changes many values at once, the targets included; correlated experience: consecutive transitions are not i.i.d., causing overfitting to recent data and catastrophic forgetting; target network: copy θˉ updated less often keeps targets fixed; replay buffer: uniform minibatches from many episodes decorrelate samples (and re-use data); off-policy: the max target estimates greedy values whatever policy acted.

(a) Moving targets: the target r+γmaxa′​Q(s′,a′;θ) uses the same parameters that are updated. A network generalises, so each step changes many values, including the targets, while a table changes one entry at a time. Learning chases a moving goal and oscillates. Correlated experience: consecutive transitions are similar and come from one region, so they are not i.i.d. The network overfits to recent experience and catastrophically forgets earlier estimates.

(b) The target network is a copy θˉ used only to compute the targets and overwritten with θ every so many steps, so the targets stay fixed in between. The replay buffer stores all transitions and trains on minibatches sampled uniformly from it, which mixes many episodes and regions; it also re-uses each transition and gives more stable batch gradients. Each fix solves only its own problem, so DQN uses both.

(c) DQN is off-policy: the max in its target estimates the greedy policy’s values, whichever policy chose the stored actions.

A robot arm must choose a continuous torque, and a good policy may need to be stochastic. (a) Give two reasons why DQN is a poor fit. (2 points) (b) Give the quantity REINFORCE uses to estimate the policy gradient, and explain its main weakness. (3 points) (c) How does A2C reduce this weakness, and what does it cost? (3 points) (d) What problem does PPO's clipping address? (2 points)

Key points: DQN needs one output per discrete action and a max over actions; ε-greedy gives only one favourite action plus uniform noise; REINFORCE uses Gt​∇ϕ​logπ(at​∣st​;ϕ), unbiased but high variance; A2C replaces Gt​ by a critic’s advantage r+γV(s′)−V(s), lower variance and single-step updates, but bias from bootstrapping and an extra network with hyperparameters; PPO clips the new-to-old probability ratio so one update cannot move the policy too far.

(a) DQN has one output per discrete action, and a max over a continuous torque is an optimisation problem at every step. Its ε-greedy policy is always one favourite action plus uniform noise, so it cannot represent an arbitrary stochastic policy.

(b) Gt​∇ϕ​logπ(at​∣st​;ϕ), with Gt​ the Monte Carlo return. It is unbiased, but returns from the same state vary a lot between trajectories, so the gradient estimates have high variance and training is unstable and slow. It also waits for the end of each episode.

(c) A2C learns a critic V and weights the log-probability by the advantage r+γV(s′)−V(s), where V(s) acts as a baseline. This lowers the variance and allows an update after each step. The cost is bias from bootstrapping on possibly inaccurate critic estimates, plus an extra component to train with its own settings.

(d) A single policy gradient update can shift the policy a lot, which destabilises training. PPO clips the ratio of new to old action probability to [1−ϵ,1+ϵ], so there is no gradient pushing the policy further once it has moved that far.

In a Coin Game, your agent learns while the opponent, built by another team, is also learning. (a) Which training and execution mode is this, and why? (2 points) (b) Your agent uses IDQN. Explain why its replay buffer becomes a problem, and give two remedies. (4 points) (c) Why can independent REINFORCE adapt faster to the opponent, and what is its main weakness here? (4 points)

Key points: DTDE, since nobody can train both agents centrally and each uses only its own observations; buffer transitions reflect the opponent’s old policy, so the agent trains on an environment that no longer exists, and off-policy learning only covers its own old actions; smaller buffer, importance sampling weights from stored action probabilities; REINFORCE is on-policy and learns from fresh experience of the opponent’s current policy; independent learning makes the already high variance of Monte Carlo returns worse.

(a) Decentralised training and execution (independent learning): the opponent is not ours to train, so each agent trains and acts on its own observations and treats the other as part of the environment.

(b) The buffer stores transitions generated while the opponent used older policies. Once the opponent changes, the same action in the same situation can lead elsewhere, so the agent keeps learning from outdated experience. DQN being off-policy does not fix this, because the opponent’s behaviour is part of the environment. Remedies: a smaller replay buffer, which keeps only recent transitions; or storing the agents’ action probabilities with each transition and reweighting replayed transitions with importance sampling weights.

(c) Independent REINFORCE is on-policy: each update uses recent episodes, generated by the opponent’s current policy, and discards them, so nothing goes stale. Its weakness is variance: Monte Carlo returns are already noisy, and the opponent’s changing policy makes them even less consistent.

L05 Deep MARL, Part II

Exam questions

Mock exam Q29 (open, 10 points): In environment A, two agents must reach the same landmark. In environment B, two agents must reach two different landmarks. In both, the agents have the same actions and observations, and swapping their policies does not change the return. (a) Define weakly and strongly homogeneous agents. Classify the agents in A and in B. (3 points) (b) Give two benefits of parameter sharing. (3 points) (c) Which environment (A or B) can use parameter sharing without observing agent indices? Explain. (2 point) (d) Which alternative suits the other environment, to still use some agent homogeneity to improve learning efficiency? (2 points)

Key points: weakly homogeneous = permuting the policies between agents does not change the returns; strongly = the optimal joint policy consists of identical policies; A strongly, B weakly homogeneous; parameter count stays constant as agents are added, and the shared parameters learn from all agents’ more diverse experience (sample efficiency); A, because its optimal policies are identical; experience sharing.

(a) Weakly homogeneous: permuting the policies between agents does not change the returns. Strongly homogeneous: the optimal joint policy consists of identical policies. A is strongly homogeneous (both agents should do the same thing, go to the one landmark). B is weakly homogeneous (swapping policies changes nothing, but the optimal policies differ, one agent per landmark).

(b) The number of parameters stays constant as agents are added. The shared parameters learn from the more diverse experience of all agents, which improves sample efficiency.

Exam questions

Describe Dennett's three stances, with an example of each. How do they relate to Sileno's distinction between objects, actors and agents?

Key points: physical stance: physical laws (billiard ball); design stance: what it was designed to do, fails when it breaks (clock); intentional stance: ascribe beliefs, desires, intentions and enough rationality to do what it ought to do (poker player, cat, countries); objects passive, actors produce changes, agents are actors ascribed intentions; agency is ascribed by an observer.

Dennett distinguishes three ways of interpreting an entity. In the physical stance we predict its behaviour from physical laws, as with a billiard ball struck by a cue. In the design stance we predict it from what it is supposed to do, what it was designed to do: we read the time from a clock without knowing its mechanism. Design-stance predictions hold only while the thing works; when the clock breaks, only the physical stance explains it. In the intentional stance we interpret the entity as an agent, ascribing it beliefs, desires and intentions and enough rationality to do what it ought to do given them, as we do with poker players, a cat’s body language, or countries in geopolitics.

Sileno’s common-sense ontology mirrors this. Objects are passive: they undergo changes due to others’ actions (an apple). Actors are active: they produce changes (a volcano, the services of a software system). Agents are actors ascribed with intentions. The word “ascribed” matters: whether something is an agent depends on whether an observer takes the intentional stance towards it, which echoes Russell and Norvig’s point that “agent” is a tool for analysis.

State Wooldridge and Jennings' four characteristics of weak agency. Use them to discuss whether a thermostat and a tool-using LLM chatbot are agents.

Key points: reactivity: perceives and responds to changes; proactivity: initiative driven by goals or intentions beyond input-output mapping; autonomy: no continuous external intervention; social ability: coordinate, compete, negotiate with other agents; thermostat reactive and autonomous, proactivity doubtful, not social; chatbot reactive, partly autonomous, proactivity depends on its harness, social only in multi-agent setups.

Reactivity: the entity perceives and responds to changes in its environment. Proactivity: it takes initiative driven by goals or intentions rather than a simple input-output mapping. Autonomy: it operates without continuous external intervention. Social ability: it interacts with other agents to coordinate, compete or negotiate.

Sileno poses the cases without verdicts; what follows is one defensible application. A thermostat is reactive (it switches the heating when the temperature changes) and autonomous (it runs alone), but its “goal”, the set temperature, is a fixed input-output mapping, so proactivity is doubtful, and it has no social ability. It is a borderline case where the intentional stance is possible but adds little, as for Russell and Norvig’s calculator. A tool-using chatbot is reactive to prompts and tool results and autonomous within a task. Its initiative comes from a goal stated in the prompt and the loop around the model, so its proactivity belongs to the harness. It is social only when placed among other agents. So it meets weak agency partly, and the open question is what would give it genuine goal-driven initiative, which is where BDI and CAES come in.

Explain Sileno's "theatrical" view of agency (EXEC, SELECT, MODIFY) and how learning fits in. Apply it to an agent whose policy was learned with Q-learning and is applied with epsilon-greedy selection.

Key points: EXEC: behaviour follows a definite script; SELECT: the script was chosen from a repertoire; MODIFY: the script was created or adapted, possibly by external events such as mutation; SELECT and MODIFY are scripts too, recursively, down to hard-coded ground; learning as feedback from effects to SELECT (which script is most effective) and MODIFY (how to make a script more effective); Q-learning: EXEC the move, SELECT epsilon-greedy over Q-values, MODIFY the Q update; update rules are the ground.

At any given time an agent’s behaviour follows a definite script, as an actor follows a play (EXEC). That script must have been chosen at an earlier point from a repertoire of scripts (SELECT), and before that it must have been created or adapted from a previous script (MODIFY), possibly by external events, as transcription errors act as mutations. SELECT and MODIFY are themselves scripts that are executed and were once selected and modified, recursively, down to some hard-coded ground. Learning enters as feedback from the effects of execution: learning at the SELECT level asks which of the available scripts is most effective; learning at the MODIFY level asks how to create or rewrite a script to be more effective.

For the Q-learning agent (Sileno leaves the exercise open; this is one defensible answer), EXEC is the move it makes in its current grid cell. SELECT is epsilon-greedy: with probability 1−ε the move with the highest Q-value, otherwise a random move from the repertoire of four. MODIFY is the Q-learning update, which revised Q-values from rewards while the policy was learned and so changed what SELECT prefers; once the policy is only applied, MODIFY is off. Read with moves as scripts, Q-learning is learning at the SELECT level; read with the policy as the script, each update is a MODIFY. The update rule and the epsilon-greedy rule are the hard-coded ground.

Why is a belief-desire architecture not sufficient for agency? Use Bratman's chocolate example, describe the three BDI levels, and explain why intention deliberation matters for an artificial agent.

Key points: Bratman: a fleeting predominant desire plus belief would count as an intention, but he was never settled on it; intention is being settled or committed; informational level beliefs, volitional level desires, deliberative level commitments (toothache, cure, dentist); intention includes side effects besides the goal; without intention deliberation an agent never weighs its possible choices; intent selection and plan selection (Georgeff and Rao).

Bratman describes a fleeting craving that makes the desire for chocolate predominant for a moment, together with a judgement that it will lead him to act. He then reflects, recalls his dieting plans and resolves to skip dessert. On a desire-belief account he had a fleeting intention to eat chocolate; Bratman says he had no such intention, because he was never settled in favour of it. Intention is therefore a distinct mental state, a settled commitment, which a belief-desire architecture cannot represent.

The BDI model separates three levels: the informational level (what the agent believes is the case: my tooth has a cavity), the volitional level (what it desires to be the case: my tooth cured) and the deliberative level (what it is committed to: going to the dentist). Committing to a conduct brings more consequences than the desired outcome, so an intention includes side effects besides the goal. Sileno’s claim is that if an architecture misses intention deliberation, it misses performing, offline or online, an evaluation and weighing of possible choices, so side effects go unexamined. Deliberation involves two selections: intent selection, prioritising which of possibly conflicting goals to advance, and plan selection, prioritising which of several plans to commit to.

Describe Sileno's CAES model and apply it to a simple LLM coding agent, using the example of a failing test. What limits such a mapping today?

Key points: commitments: what the agent wants to achieve (intent selection); abilities: what it can achieve and how (plan selection); expectations: what it knows about the world (belief revision); susceptibilities: what it looks at and how it responds (attention allocation); coding agent: task, constraints, guardrails, completion criteria; SKILL.md, tools, runtime; context, memory, repository, evidence; watchers, handlers, interrupts, escalation; test fails: S, E, C, A cycle; low-level constructs lack an interoperable declarative language, higher-level directives are interpreted unpredictably by the LLM.

CAES (Boer and Sileno) regroups the tangled BDI picture: commitments take over desires and intent, abilities take over plans, expectations take over percepts and beliefs, and susceptibilities are new. Commitments are what the agent wants to achieve in the world, decided by intent selection. Abilities are what it can achieve and how, used in plan selection. Expectations are what it knows about the world, maintained by belief revision. Susceptibilities are what it is looking at in the world and how it responds, set by attention allocation. Commitments and abilities meet on the acting side, expectations and susceptibilities on the perceiving side.

In a coding agent harness, commitments are the task (“fix the bug”), constraints (“preserve the API”), guardrail checks (“don’t edit unrelated files”) and completion criteria (“the bug is fixed and relevant tests pass”). Abilities are the SKILL.md files exposing tool usage, the tools, and the system running them. Expectations are the working context, memory, the code repository and retrieved evidence, or models of them. Susceptibilities are watchers and triggers, tool-result handlers, interrupts and escalation routing. When a test fails, the failure is received and routed (S), the context is updated (E), the agent identifies the problem and commits to repairing the bug (C), and it chooses an available debugging skill (A): a problem-solving cycle.

The mapping is limited because it relies either on low-level constructs, for which no sufficiently interoperable declarative language exists yet, or on higher-level directives in natural language, whose interpretation by the LLM we cannot know in advance.

Distinguish an "AI agent" from "agentic AI" as commonly defined, and the two opposite approaches to agentic AI. Is a tool-using chatbot an agent?

Key points: AI agent: autonomous system where an LLM decides what to do next, which tools to use, when the task is complete (Sileno: strictly speaking wrong); AI agent ≈ LLM + harness (planning, memory, tool use, guardrails); agentic AI: orchestrates multiple tools including LLMs to make decisions and execute actions towards an outcome; agentic workflow: workflow governs agents; autonomous agent: agents govern workflow (improving the harness); chatbot meets the minimal definition but lacks deliberation (Sileno leaves the verdict open); CAES-like frameworks for rational agents.

In current usage an AI agent is an autonomous system in which an LLM decides what to do next, which tools to use and when the task is complete; Sileno calls this the common sense of the term but strictly speaking wrong. Architecturally it is an LLM, the “brain”, plus a harness or scaffolding of planning, memory, tool use, guardrails and more; intelligent behaviour comes from orchestrating these components. Agentic AI is an autonomous system performing complex multi-step tasks by orchestrating multiple computational tools, including LLMs, to make decisions and execute actions towards a desired outcome: several agents around an orchestrator. In an agentic workflow the workflow governs the agents; with autonomous agents the agents govern the workflow, for example by improving their own harness.

Sileno leaves the verdict open; putting his criteria together, a tool-using chatbot has a body of sorts (its tools), memory (its context) and an implicit purpose (the prompt), so it meets his minimal definition of an intelligent agent, and we can take the intentional stance towards it. It lacks what makes an intentional, rational agent: explicit commitments, deliberate intent and plan selection that weigh choices and their side effects, and explicit attention to what matters. Sileno concludes that building rational agents means moving towards CAES-like frameworks.

Describe the two main approaches to agent-based modelling and the two traditional approaches to ABM in game theory.

Key points: cellular automata with if-then rules (Rule 22, Game of Life, Schelling); agent-oriented programming (BDI) more expressive in the same arena; equations (ODE, PDE), traditionally economics; network science for spreading dynamics; classic game theory: perfectly rational, forward-looking, few different agents; evolutionary: bounded, replicative and adaptive, many similar agents.

In agent-based modelling, agents’ behaviour is specified either as cellular automata, generally if-then rules by which each cell updates from its neighbours (Rule 22: a cell becomes 1 if exactly one cell in its three-cell neighbourhood is 1; Conway’s Game of Life; Schelling’s segregation model), or as equations, possibly differential ones, traditionally more associated with economics. Agent-oriented programming, for example of BDI agents, is a more expressive approach in the same arena as cellular automata. When studying spreading dynamics, the topology of who can interact with whom matters, which brings in network science.

Classic game theory assumes perfectly rational agents with forward-looking cognition, anticipating and deciding before acting, usually few and different from one another, as in the Prisoner’s Dilemma. Evolutionary game theory assumes bounded, possibly non-rational agents whose cognition is replicative (imitation) and possibly adaptive, usually many and similar, studied with replicator dynamics.

Is the simple reflex vacuum agent (suck if dirty, otherwise move to the other square) rational? Under what conditions, and when would it stop being rational?

Key points: rationality depends on performance measure, prior knowledge, actions and percept sequence; rational under the book’s assumptions (1 point per clean square per step over 1000 steps, known geography, deterministic actions, correct sensing); irrational if movement costs, if dirt reappears, or if geography is unknown; rationality is relative to expected performance.

A rational agent selects, for each percept sequence, the action expected to maximise its performance measure given its percepts and built-in knowledge. So “is it rational?” has no answer until we fix the four things rationality depends on: the performance measure, the agent’s prior knowledge, the available actions and the percept sequence.

Under Russell and Norvig’s assumptions the agent is rational. The performance measure gives one point per clean square per time step over 1000 steps. The two-square geography is known, but the dirt distribution and the start square are not. Clean squares stay clean, Suck cleans the current square, and Left and Right move one square (or leave the agent in place at the wall). Only Right, Left and Suck are available, and the agent correctly perceives its location and whether there is dirt. No other agent can then do better in expectation: it cleans any dirty square at once and reaches the other square in one step.

Change the circumstances and it becomes irrational. If each move costs a point, it keeps oscillating after both squares are clean and loses points; a better agent would do nothing once it is sure all squares are clean. Russell and Norvig leave that design as an exercise, but being sure takes memory: the local dirt sensor cannot see the other square, so the agent must remember having found it clean, which a simple reflex agent, acting on the current percept alone, cannot do. If clean squares can get dirty again, it should check occasionally and re-clean. If the geography is unknown, it should explore. The same agent function can be rational in one task environment and irrational in another.

Give a PEAS description for an automated taxi and classify taxi driving along each environment dimension, with a justification for each.

PEAS. Performance: safe, fast, legal, comfortable trip, maximise profits, minimise impact on other road users (these conflict, so tradeoffs are needed). Environment: roads, other traffic, police, pedestrians, customers, weather. Actuators: steering, accelerator, brake, signal, horn, display, speech. Classification.

  • Partially observable: the taxi cannot see round a truck or know what other drivers intend.
  • Multiagent: other drivers’ behaviour is best described as maximising their own performance measures, which depend on the taxi’s actions. Partially cooperative (everyone wants to avoid collisions) and partially competitive (one parking space, one car).
  • Nondeterministic (stochastic): traffic cannot be predicted exactly, tyres blow out, engines seize.

  • Dynamic: the world keeps moving while the driving algorithm deliberates; not deciding counts as doing nothing.
  • Continuous: positions, speeds, time and steering angles all vary continuously.
  • Known (mostly): the driver knows how the car and traffic rules work. Known/unknown is about the agent’s knowledge, not the environment itself; driving a rental car in an unfamiliar country would make it unknown too.

Explain the difference between rationality and omniscience. Why do information gathering, learning and autonomy follow from the definition of rationality?

Key points: omniscient agent knows actual outcomes, impossible; rationality maximises expected performance, perfection actual performance (Champs Elysées example); crossing without looking is irrational, looking is information gathering; agent must learn from percepts (dung beetle, sphex wasp as failures); autonomy: rely on own percepts and learning to make up for partial or wrong prior knowledge.

An omniscient agent knows the actual outcome of its actions and can act accordingly; this is impossible in reality. Rationality only asks the agent to maximise expected performance given its percept sequence to date. Someone who crosses an empty street and is hit by a cargo door falling from an airliner acted rationally: the outcome was bad, but the choice was right given the evidence. Requiring the best action in hindsight would make the specification impossible to meet.

This does not let an agent excuse itself by not looking. Crossing a busy road with an uninformative percept sequence is not rational, because the expected cost is too high, and choosing to look first is rational, because looking raises expected performance. Acting to change future percepts is information gathering; exploring an unknown environment is another example.

The definition also requires learning from what is perceived. An agent that relies only on built-in assumptions is fragile: the dung beetle mimes plugging its nest after the dung ball is removed, and the sphex wasp repeats its drag-and-check routine endlessly when the caterpillar is moved. Neither can learn that its plan is failing. An agent that relies on its designer’s prior knowledge instead of its own percepts and learning lacks autonomy. A rational agent should be autonomous enough to compensate for partial or incorrect prior knowledge, though it is sensible to start with some built-in knowledge, as evolution gives animals reflexes.

Why is it hard to choose a performance measure? Use the vacuum world to illustrate, state Russell and Norvig's general rule, and connect it to reward hacking.

Key points: performance measure scores sequences of environment states (consequentialism); “dirt cleaned up” is maximised by dumping and re-cleaning; better: points per clean square per time step (minus energy, noise); rule: measure what you want achieved in the environment, not how the agent should behave; reward hacking: optimiser exploits the gap between measure and purpose (Wiener, King Midas), and the flaw may only appear when new actions become available (Lab 1 Dump).

Russell and Norvig judge agents by consequences: a performance measure scores the sequence of environment states the agent’s actions produce. Machines have no preferences, so the measure comes from the designer, and writing it down correctly is hard because a rational agent gives you exactly what you ask for.

If the vacuum agent is scored on the amount of dirt it cleans up in a shift, it can maximise the score by cleaning, dumping the dirt back and cleaning again. The measure described a behaviour the designer imagined. Scoring one point per clean square per time step, perhaps minus a penalty for electricity and noise, describes the state of the world the designer actually wants. Hence the rule: design performance measures according to what one actually wants to be achieved in the environment, rather than according to how one thinks the agent should behave.

The course calls this reward hacking (specification gaming), a term the book does not use: an optimiser finds behaviour that scores well on the stated objective while defeating its purpose, which is Wiener’s warning that the purpose put into the machine must be the one we really desire, and the King Midas problem. Distinguish the agent function from the agent program. Write the table-driven agent and explain why this approach is doomed.

Key points: agent function maps percept sequences to actions (abstract); agent program implements it, receives only the current percept; TABLE-DRIVEN-AGENT appends percept and looks up the whole sequence; table size is the sum over t of |P|^t; cannot be stored, built or learned; goal of AI is small programs that produce rational behaviour.

The agent function is an abstract mathematical description: it maps every possible percept sequence to an action. The agent program is a concrete implementation running on the agent architecture (agent = architecture + program). The program receives only the current percept, since that is all the environment provides, so if the action must depend on history the program has to remember it.

With a correct table it implements any desired agent function. But with a set of percepts P and lifetime T, the table has ∑t=1T​∣P∣t entries. For an hour of taxi driving from camera input that is over 10600,000,000,000, and even chess needs at least 10150, against fewer than 1080 atoms in the observable universe. So no agent could store the table, no designer could write it, and no agent could learn all its entries. The challenge for AI is to get rational behaviour from a compact program, as Newton’s method replaced square-root tables; even the four-line reflex vacuum agent replaces an infinite table by ignoring history.

Describe the simple reflex, model-based reflex, goal-based and utility-based agents. What does each add to the previous one, and in what kind of environment does each fail?

Key points: simple reflex: condition-action rules on the current percept, needs full observability, loops otherwise (randomisation helps a little); model-based: internal state updated with transition and sensor models, handles partial observability, still rule-based; goal-based: predicts future states and picks actions that reach goals, flexible because knowledge is explicit; utility-based: utility function grades states, handles conflicting goals and uncertain success, maximises expected utility.

A simple reflex agent chooses from the current percept alone through condition-action rules (if car-in-front-is-braking then initiate-braking). It is small and fast but works only in fully observable environments. A vacuum agent with no location sensor that always moves the same way on [Clean] loops forever in one of the two start squares; randomising between Left and Right escapes the loop, but randomisation is rarely rational in single-agent settings.

A model-based reflex agent adds internal state that tracks what it cannot currently see. It updates the state each step with a transition model (how actions change the world and how the world evolves by itself) and a sensor model (how states show up in percepts): state ← UPDATE-STATE(state, action, percept, transition model, sensor model), then matches rules as before. This handles partial observability (the state is a best guess), but behaviour is still fixed rules with no look-ahead.

A goal-based agent adds goals and uses the model to predict “what it will be like if I do action A”, choosing actions (or, via search and planning, action sequences) that achieve the goal. It considers the future and knows why it acts. It is more flexible: change the destination and the behaviour changes, whereas reflex rules would all need rewriting. But goals are binary.

A utility-based agent replaces goals with a utility function, an internalisation of the performance measure, and chooses the action with the highest expected utility, ∑s′​P(s′∣s,a)U(s′). It handles conflicting goals (speed against safety) and goals that may not be reached (weighing likelihood against importance). But modelling the world and computing the best action is hard, and perfect rationality is usually computationally out of reach.

Key points: performance element selects actions (the old agent); learning element improves it using feedback; critic judges behaviour against a fixed performance standard; problem generator suggests exploratory actions; percepts carry no verdict on success, so a standard is needed; the agent must not adapt the standard to its own behaviour; exploration trades short-term loss for long-term gain (Galileo).

The performance element takes percepts and selects actions: it is what the earlier designs called the whole agent. The learning element improves the performance element, and its design depends on what the performance element looks like. The critic tells the learning element how well the agent is doing with respect to a performance standard. The problem generator suggests actions that lead to new, informative experiences.

The critic is needed because percepts do not say whether they are good: a chess program perceives checkmate but needs a standard to know checkmate is good. The standard must be fixed and conceptually outside the agent, because the agent must not modify it to fit its own behaviour; if it could, it could improve its score by changing the standard instead of its behaviour. The standard effectively marks part of each percept as reward or penalty, like pain and hunger in animals.

Left alone, the performance element keeps choosing the best action given what it knows. The problem generator proposes perhaps suboptimal exploratory actions that may reveal better ones in the long run, like Galileo’s experiments at Pisa. Learning in general means modifying each component of the agent to bring it into closer agreement with the available feedback, thereby improving overall performance.

Explain atomic, factored and structured representations of state with an example of each. What is gained and lost as representations become more expressive? How does a distributed representation differ from a localist one?

Key points: atomic: state is a black box (city name; search, MDPs); factored: fixed set of variables with values (fuel, GPS, money; CSPs, propositional logic, Bayesian networks); structured: objects with attributes and relations (truck, cow, driveway; first-order logic, databases); more expressive is more concise (chess rules: a page or two, thousands of pages, about 10^38 pages) but harder to reason and learn with; localist one concept per location, distributed spread over many, robust to noise.

In an atomic representation a state has no internal structure: for route-finding it is just the name of the city you are in, and two states are only ever the same or different. Search, game playing, hidden Markov models and Markov decision processes use atomic states. A factored representation splits the state into a fixed set of variables with values: fuel level, GPS position, toll money. Two states can share some values, which makes it easier to see how to turn one into another; constraint satisfaction, propositional logic, planning and Bayesian networks use it. A structured representation describes objects, their attributes and their relations, which a scene like a truck reversing into a farm driveway blocked by a loose cow needs; first-order logic, relational databases and natural language understanding use it.

More expressive representations capture everything less expressive ones can, usually far more concisely: the rules of chess take a page or two in first-order logic, thousands of pages in propositional logic and about 1038 pages as a finite-state automaton. The cost is that reasoning and learning get harder, so real systems may need all three levels at once.

A localist representation maps each concept to one memory location; a distributed representation spreads each concept over many locations, each shared with other concepts. Distributed representations are more robust: a few garbled bits move the concept to a nearby point with similar meaning, while in a localist code they can turn Truck into the unrelated Truce.

A symmetric game has R = 5, S = 0, T = 3, P = 1. (a) Which motives (greed, fear) does it have, and what kind of game is it? (b) Find the pure Nash equilibria and the social optimum. (c) Above which belief that the partner cooperates is C the best response? (d) What happens under the replicator dynamics from 50% cooperators?

Key points: no greed (3 < 5), fear (1 > 0): a Stag Hunt; pure NE (C, C) and (D, D), social optimum (C, C) with total 10; p∗=1/3; from 50%, above the tipping point 1/3, so cooperators grow to all C.

(a) T=3<R=5: no greed. P=1>S=0: fear. R>T>P>S, so it is a Stag Hunt, a trust problem.

(b) At (C, C) deviating gives 3 < 5; at (D, D) deviating gives 0 < 1; at (C, D) the cooperator gains by switching (1 > 0). Pure equilibria: (C, C) and (D, D). Totals 10, 3, 3, 2, so (C, C) is the social optimum (and the only Pareto-optimal cell).

(c) p∗=(R−T)+(P−S)P−S​=2+11​=31​. Here the gain (2) beats the fear (1), so (C, C) is the equilibrium played more often by agents with uniform beliefs.

(d) fC​−fD​=x(R−T)+(1−x)(S−P)=2x−(1−x)=3x−1, positive above 1/3. At x=1/2, C earns 2.5 and D earns 2, so cooperators grow until everyone cooperates. Below 1/3 the population would go to all D.

In a large population playing a Prisoner's Dilemma (T > R > P > S) under the replicator dynamics: (a) write fC​−fD​ in terms of the payoffs and the cooperator share x, (b) explain why cooperators die out from any start, and (c) explain why all-C is a rest point but not a stable one.

Key points: fC​−fD​=x(R−T)+(1−x)(S−P); greed makes the first term negative and fear the second, so x˙<0 for every interior x; all-D is the stable outcome and matches the NE (D, D); all-C rests only because nobody defects, and one defector earns T > R and spreads.

(a) A partner cooperates with probability x, so fC​=xR+(1−x)S and fD​=xT+(1−x)P, giving fC​−fD​=x(R−T)+(1−x)(S−P).

(b) Greed (T>R) makes R−T<0 and fear (P>S) makes S−P<0. The difference is an average of two negative numbers, so D earns more against every mix, and x˙=x(1−x)(fC​−fD​)<0 between 0 and 1. Even 90% cooperators decline to 0, the Nash equilibrium (D, D).

(c) At x=1 there are no defectors to copy, so x˙=0. But a single defector among cooperators earns T against their R<T, so its share grows: a small push sends the population away, which makes the rest point unstable.

In a repeated Prisoner's Dilemma ( R=3,S=0,T=5,P=1), explain why memory matters for cooperation, why AllD can win a round robin with AllC, AllD, Random, TFT and WSLS, and why TFT beats AllD when only AllD, TFT and WSLS take part in a long game.

Key points: memory-0 strategies cannot react to the partner; TFT is exploited only in round 1 and earns 3 per round with cooperators; AllD’s score comes from exploiting AllC, Random and WSLS; with no exploitable partners AllD’s one-off first-round gain is diluted, and TFT wins from 4 rounds.

Memory. AllC, AllD and Random play the same way whoever they meet, so an unconditional cooperator is exploited every round. TFT and WSLS condition on the last round: TFT cooperates with cooperators and defects against AllD from round 2, capping its loss at one round.

Why AllD wins the five-strategy field. It earns 5 per round from AllC and about 3 from Random and from WSLS, which counts mutual defection as a loss and returns to C every other round. Against TFT it earns little more than 1. Its win is paid for by exploitable partners.

Three-strategy field. Without them, AllD gets 5 once against TFT and then 1 per round, while TFT and WSLS earn 3 per round from each other. From 4 rounds on that one-off gain is too diluted, and TFT ranks first.

Mock Q12 (open, 10 points): Two independent Q-learners play a Stag Hunt with R = 4, S = 0, T = 3, P = 2. They use the stateless update Q(a) ← Q(a) + α(r − Q(a)) and ε-greedy exploration. (a) Early in learning the partner plays almost at random. Compute the expected payoff of C and of D against a 50/50 partner. (2 points) (b) Both agents start at Q = (0, 0). Explain why they usually lock into (D, D). (2 points) (c) Explain why escaping from (C, C) to (D, D) is much more likely than escaping in the other direction. (3 points) (d) An agent with belief b about its partner starts with Q(C) = 4b and Q(D) = 3b + 2(1 − b). For which b does it start by playing C? What happens when an agent with b = 0.9 meets an agent with b = 0.5, with little exploration? (3 points)

Key points: C earns 2, D earns 2.5; D always earns at least 2 while C earns 0 against D, and once both play D, Q(C) is updated only in exploration, where it mostly earns 0; from (C, C) a few exploratory D moves push Q(C) below Q(D), while leaving (D, D) needs both agents to explore C in the same rounds; b > 2/3; the b = 0.9 agent earns 0 and its Q(C) falls, the b = 0.5 agent earns 3 and keeps D, so they end at (D, D).

(a) C: 0.5⋅4+0.5⋅0=2. D: 0.5⋅3+0.5⋅2=2.5.

(b) D always earns at least 2. C only pays off if the partner also plays C at that moment, and it earns 0 otherwise, so it is riskier than receiving 2 by playing D. Once both play D, Q(D) goes to 2, and Q(C) is updated only during exploration, where it mostly earns 0 (the partner plays D). So Q(C) never gets evidence that C can pay 4. Bonus: (D, D) is the risk-dominant equilibrium.

(c) From (C, C), a few exploratory D moves by one agent lower the other’s Q(C) below Q(D): playing C against D pays 0, and with a constant learning rate each 0 cuts Q(C) by 10% (3.8→3.42→3.08→2.77<2.95). That agent switches to D, and its partner then earns 0 and follows. From (D, D), Q(C) must rise above Q(D), which needs both agents to explore C in the same rounds (chance (ε/2)2 per round), several times, and both must switch together. That is far less likely.

(d) 4b>b+2 gives b>2/3. With b=0.9 the agent plays C (Q=(3.6,2.9)), and with b=0.5 the agent plays D (Q=(2,2.5)). The first agent earns 0, and its Q(C) falls quickly (3.6→3.24→2.92→2.62<2.9, so it switches after three rounds). The second earns 3 and keeps D; it never plays C, so it never learns that stag can pay 4. They end at (D, D).

Mock Q21 (open, 10 points): Tabular Q-learners play the Coin Game, whose table has 1,458 rows. Each of k random lamps doubles the number of rows (as lamps can be on or off). Training plays 300 updates, each with 32 parallel games of 16 steps, and every step gives one decision per agent. Coins per episode are 14.5 with no lamps and 4.9 with 8 lamps, while random agents collect 3.7. (a) Compute the number of rows N for k = 0 and k = 8, and the budget B of decisions per agent. (3 points) (b) Use these numbers to explain the drop in performance. Why can't agents with tabular learning discover that the lamps do not matter? (3 points) (c) Explain how a neural network avoids this problem. Name one new challenge it introduces. (4 points)

Key points: N=1,458 for k=0 and 1,458⋅28 for k=8, B=300⋅32⋅16; rows grow while the budget stays, so most rows are never visited and unvisited rows hold zeros (random play); rows that differ in one lamp share nothing, so each lesson is relearned for every lamp pattern; a network computes values or a policy from the observation with shared weights, so what it learns about the coin’s position applies to all lamp patterns and the lamps get little weight; new challenges: instability from moving targets or correlated data, possible divergence, no general convergence guarantee, more computation.

(a) N=1,458 for k=0, and N=1,458⋅28=373,248 for k=8. B=300⋅32⋅16=153,600 decisions per agent.

(b) With 8 lamps, most rows are never visited, and the others only a few times (about 0.4 decisions per row, against about 105 without lamps). An unvisited row still holds zeros, so the agent acts at random there. The number of rows grows but the budget remains, so the probability of visiting each state becomes too low, and performance falls from 14.5 coins to 4.9, close to random (3.7). Two rows that differ in one lamp share nothing, so each lesson must be learned again for each of the other lamp patterns; that is why the table cannot discover that the lamps do not matter.

(c) A network computes values or a policy as a function of the observation, with shared weights. What it learns about the coin’s position applies to all lamp patterns, and it can give the lamps little weight. New challenges: instability from moving targets or correlated data, possible divergence, no general convergence guarantee, and more computation needed.

Two independent Q-learners play a Prisoner's Dilemma with R = 3, S = 0, T = 5, P = 1, using the stateless update and ε-greedy exploration. (a) Compute the expected payoff of C and of D against a 50/50 partner. (2 points) (b) The learners always end at (D, D). Is this a coordination failure, as in the Stag Hunt? Explain. (3 points) (c) An agent with belief b that its partner cooperates starts with Q(C) = 3b and Q(D) = 5b + (1 − b). For which b does it start with C? (2 points) (d) Both agents start with Q = (3, 1) and play (C, C). Explain why exploration makes them leave. (3 points)

Key points: C: 1.5, D: 3; no: D is dominant (T > R, P > S), so (D, D) is the only Nash equilibrium and the learners found it, the bad outcome is a social dilemma; 3b > 4b + 1 has no solution in [0, 1], so D for every belief; exploratory D earns T = 5 > R = 3 and raises Q(D), the partner’s exploratory D gives 0 and lowers Q(C), so Q(D) overtakes Q(C), and then the partner earns 0 and follows.

(a) C: 0.5⋅3+0.5⋅0=1.5. D: 0.5⋅5+0.5⋅1=3.

(b) No. D is dominant: against C it earns T=5>R=3, against D it earns P=1>S=0. So (D, D) is the only Nash equilibrium, and the learners found it. (C, C) gives both more, but it is not an equilibrium, so there was nothing better to coordinate on. The bad outcome is a social dilemma, an incentive problem. In the Stag Hunt (C, C) is an equilibrium that the learners miss, which is a coordination failure.

(c) Q(D)=4b+1, and 3b>4b+1 would need b<−1. No belief makes C the first choice: D is the best response to anything.

(d) At (C, C) each agent’s Q(C) sits near 3. In the Coin Game a pickup pays +1 to the picker whatever the coin's colour, and the coin's owner gets −2 when the other agent takes it. Two independent Q-learners pick up many coins, but only about half are their own colour. (a) Show that welfare (total reward) = pickups × (2 × own share − 1), and compute the expected total reward per pickup for colour-blind agents. (3 points) (b) Explain, from one agent's own reward, why taking the other's coin is never worse than leaving it. (3 points) (c) Why can independent Q-learning not learn restraint by itself? (2 points) (d) Would independent PPO agents behave differently? (2 points)

Key points: own pickup adds +1 to the total, other’s pickup +1 − 2 = −1, so welfare = pickups × (share − (1 − share)); colour-blind: 0 per pickup; taking pays +1, leaving pays 0 now and 0 if the other takes it, the −2 falls on the other agent; the other is part of the environment and the state has no record of its behaviour, so no reciprocity, and taking is the best response to any fixed behaviour; PPO generalises better but optimises the same selfish reward, so it also takes the other’s coins.

(a) A pickup of one’s own coin adds +1 to the total; a pickup of the other’s coin adds +1−2=−1. With n pickups and own share p, welfare =np−n(1−p)=n(2p−1). Colour-blind agents have p=1/2, so the expected total per pickup is 21​−21​=0.

(b) Taking the coin pays the agent +1. Leaving it pays 0 now, and if the other then takes it, the agent still gets 0 (it is the other’s coin). The −2 that taking causes falls on the other agent, so it never enters the taker’s reward or Q-values. Taking is at least as good in every state, like D in the Prisoner’s Dilemma.

(c) Each agent maximises its own return and treats the other as part of the environment. Restraint costs +1 and helps only the other, and the state holds positions and the coin with no record of the other’s past behaviour, so neither agent can reward restraint or punish taking. Against any fixed behaviour of the other, taking every coin is the best response.

(d) No. PPO handles irrelevant inputs better, but each PPO agent still optimises its own reward with the other treated as environment, so taking every coin is still its best response: restraint stays near 0.5 and welfare near 0.
