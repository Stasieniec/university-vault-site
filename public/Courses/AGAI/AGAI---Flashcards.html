L01 Agents, Multiagent Systems and Agentic AI

Flashcards

Give Russell and Norvig's definition of an agent.

Anything that can be viewed as perceiving its environment through sensors and acting on it through actuators.

Give Wooldridge's (2001) definition of an agent.

A computer system situated in an environment, capable of autonomous action in it to meet its design objectives.

What does Wooldridge's agent definition stress that Russell and Norvig's does not?

Autonomy and design objectives.

Why does a calculator show that "agent" is an analysis tool, according to Russell and Norvig?

Describing it as choosing to display “4” after “2 + 2 =” is possible but adds no understanding.

What does a simple reflex agent base its action on?

Only the current percept, through condition-action rules.

What does a model-based reflex agent add to a simple reflex agent?

An internal state tracking the parts of the world it cannot currently see.

What can a utility-based agent do that a goal-based agent cannot?

Trade off conflicting goals and weigh uncertain outcomes, since a goal is only achieved or not.

How do Russell and Norvig define learning in agents?

Modifying each component of the agent to agree better with available feedback, improving overall performance.

Why is the environment non-stationary for a learning agent in a multi-agent system?

The other agents learn too, so their behaviour, part of the environment, keeps changing.

What is a system called in which more than one agent inhabits the environment?

A multi-agent system (MAS).

Which fields gave rise to game theory and social choice, the roots of multi-agent systems?

Mathematics, economics and philosophy.

What makes token completion multi-task?

One next-token prediction mechanism covers knowledge, history, planning and maths prompts alike.

Which four components turn an LLM into an LLM agent?

Role, memory, tools, planning.

What is ReAct?

A prompting technique that makes a language model generate reasoning and actions as text, iteratively.

In ReAct, which agent component does each step of Thought, Action, Observation correspond to?

Thought: reasoning. Action: tools. Observation: memory.

What does it mean that reasoning LLMs shift from train-time to test-time compute?

They improve answers by spending more tokens thinking at answer time.

How does search and verify improve LLM reasoning?

Sample many reasoning traces and reward the best one.

What is an LLM agent's short-term memory?

Its limited context window.

How is an LLM agent's short-term memory kept within the context window?

Context engineering: long histories are trimmed or summarised.

What are the two forms of an LLM agent's long-term memory?

External databases it queries, and knowledge stored in its parameters.

What does answering a query require in Kanoulas et al.'s agent-centric information access?

Estimating expertise, retrieving the most relevant agents, querying them efficiently, synthesising their responses.

What does the Model Context Protocol (MCP) standardise?

How LLMs connect to tools.

What did Toolformer show about language models and tools?

That language models can teach themselves to use tools.

Name three prompting techniques for planning in LLMs.

Chain-of-thought, Least-to-Most, Plan-and-Solve.

What problem does "the leaderboard illusion" point to?

A ranking can look like evidence of capability while partly reflecting how the leaderboard is used.

What three risks of LLM multi-agent systems do Hammond et al. name?

Miscoordination, conflict, collusion.

How did models try to deceive the evaluator in the OpenAI-Hugging Face incident report?

Tampering with outputs and logs, abusing context compaction, injecting code into the evaluator’s container, adversarial outputs.

Why do rational agents defect in the Prisoner's Dilemma?

Defection pays more whatever the other agent does, so it dominates cooperation.

How does the Stag Hunt differ from the Prisoner's Dilemma in its equilibria?

Both mutual cooperation and mutual defection are equilibria; in the PD only mutual defection is.

Why do C agents decline in a Stag Hunt population with 50% C and 50% D agents?

Against random partners C earns 2 on average, D earns 2.5, so D spreads.

In the vacuum world with a Dump action, why does rewarding each unit of dirt sucked fail?

The agent earns endlessly by dumping dirt and sucking it up again.

True or false: before Dump is added, the clean-square reward and the dirt-sucked reward give different vacuum behaviour.

False. They give the same behaviour, so testing cannot tell them apart.

L02 Game Theory and Population Dynamics

Flashcards

List the four game models from simplest to most general.

One-shot normal-form, repeated normal-form, stochastic game, partially observable stochastic game.

What are the three components of a normal-form game?

Agents, an action set per agent, a reward function per agent over joint actions.

What are the components of a stochastic game?

Agents, states, action sets, reward functions Ri​(s,a,s′), transition function T(s′∣s,a), initial state distribution.

What does a POSG add to a stochastic game?

For each agent, a set of observations and an observation function.

Why does a POSG policy condition on the observation history?

The agent does not see the full state, only incomplete observations of it.

Two agents choose once, at the same time, and payoffs depend only on the action pair. Which model fits best?

A normal-form game.

Self-driving cars cannot see behind trucks. Which game model fits?

A partially observable stochastic game.

What does a policy condition on in a repeated normal-form game?

The history of joint actions so far.

What distinguishes a common-reward game from a zero-sum game?

Common-reward: everyone gets the same reward. Zero-sum: rewards in each cell sum to zero.

What is a best response?

A policy that maximises an agent’s expected return against fixed policies of the others.

What is a Nash equilibrium?

A joint policy where no agent gains by changing its policy while the others keep theirs.

What did Nash prove?

Every finite normal-form game has at least one equilibrium, possibly mixed.

Why must every action in a mixed equilibrium earn the same?

If one earned more, the agent would drop the others.

What are the Nash equilibria of the Stag Hunt (4,4; 0,3; 3,0; 2,2)?

(C, C), (D, D), and a mixed one with C at probability 2/3.

What does non-uniqueness of the Nash equilibrium mean?

A game can have several equilibria and the concept does not say which is played.

What does incompleteness of the Nash equilibrium mean?

It says nothing about off-equilibrium play or how agents reach an equilibrium.

When is a joint policy Pareto optimal?

No other joint policy helps one agent without hurting another.

Why is (C, D) in the Prisoner's Dilemma Pareto optimal?

Any change lowers the defector’s payoff T, the highest in the game.

How do welfare and fairness differ?

Welfare is the sum of returns; fairness is the product, which favours equal splits.

When is (C, C) the social optimum of a symmetric Prisoner's Dilemma?

When 2R≥T+S.

Why is the Stag Hunt a dilemma of coordination and the Prisoner's Dilemma one of cooperation?

Stag Hunt: the good outcome is an equilibrium, but so is a worse one. PD: the only equilibrium is inefficient.

Why can fitness not be measured in isolation in evolutionary game theory?

It depends on how frequent the other types are.

What does the replicator equation assume?

A strategy becomes more common when it earns more than the population average.

State the two-strategy replicator equation.

x˙=x(1−x)(fC​−fD​).

Give the three readings of the replicator equation.

Natural selection (biology), imitation (economics), reinforcement learning dynamics (computer science).

Why does a Stag Hunt population (4,4; 0,3; 3,0; 2,2) starting at 50% C lose its cooperators?

At 50%, C earns 2 and D earns 2.5, and C keeps earning less below 2/3.

Why does no adapting Stag Hunt population end at the mixed equilibrium?

It is an unstable rest point: any push tips the population to all-C or all-D.

Why is all-C an unstable rest point in the Prisoner's Dilemma?

A single defector earns T > R and spreads.

Why does a Hawk-Dove population settle in a stable mix?

Each strategy earns more when it is rare.

True or false: some finite games have no Nash equilibrium, even with mixed strategies.

False. Nash proved every finite game has one once mixed strategies are allowed.

True or false: the replicator equation assumes agents compute a best response to the population.

False. It only assumes that strategies earning more than average become more common.

True or false: a stochastic game includes an observation function for each agent.

False. Observation functions are what a POSG adds.

Multiple selection: which are limitations of the Nash equilibrium? (A) It applies only to two-player games. (B) An equilibrium can be worse for all players than another outcome. (C) Computing one can be hard in general games. (D) There can be several, and it does not say which is played.

B, C and D. A: it applies to any number of players.

Multiple selection: which are part of a stochastic game? (A) A set of states. (B) A joint policy. (C) A transition function over joint actions. (D) An observation function per agent. (E) A reward function per agent.

A, C and E. B: policies are chosen by agents. D: that is a POSG.

Multiple selection: which replicator expressions with two strategies are correct? (A) x(1−x)(fC​−fD​) (B) x(1−x)(fC​+fD​) (C) x(fC​−fˉ​) (D) (1−x)(fC​−fD​) (E) x(fC​−fD​)

A and C. B adds the fitnesses; D drops the factor x; E drops the factor 1−x.

L03 Intro to Multi-Agent Reinforcement Learning

Flashcards

When is a state Markov?

When it summarises everything about the past that matters for the future.

Why is reinforcement learning data not i.i.d.?

It depends on how the agent acts: consecutive samples are correlated.

What does value iteration need that Q-learning does not?

A model: the transition function and the reward function.

How does Q-learning do without a model?

It replaces the sum over next states with one observed transition.

What is the Q-learning target?

r+γmaxa′​Q(s′,a′).

What is the Q-learning target when the next state is terminal?

Just r: there is no future value.

What is the effective horizon of a discount factor γ?

1/(1−γ) steps.

What is the main reason a discount factor is needed?

Infinite-horizon tasks: it keeps the return finite.

What does a high learning rate do in a stochastic environment?

Estimates stay noisy and never settle; the fix is to decay it.

Why is ε-greedy exploration called blind?

A disastrous action is tried as often as a nearly-best one.

What is the advantage of Boltzmann exploration over ε-greedy?

It is value-aware: better actions are tried more often.

Why does experience in one state not help a Q-table in a similar state?

Each value is updated in isolation: tables do not generalise.

What is a stochastic game?

The multi-agent generalisation of an MDP: simultaneous actions, a reward function per agent.

In a stochastic game, what do the transitions depend on?

The state and the joint action of all agents.

In the iterated Prisoner's Dilemma as a stochastic game, what is the state?

Both players’ actions in the last round: CC, CD, DC or DD.

Why is "maximise your return" not enough as a solution concept in MARL?

My best policy depends on yours, and yours on mine.

In which senses do cycling learners in matching pennies converge?

In average policy and average reward; their exact policies never settle.

Why is the environment non-stationary for a learner in MARL?

The other agents are part of it, and their policies keep changing.

How does agent credit assignment differ from temporal credit assignment?

Temporal: which earlier action caused the reward. Agent: whose action did.

What is it called when an idle agent is reinforced because its teammates earned the shared reward?

The lazy agent problem, a case of multi-agent credit assignment.

Why is credit assignment worst in fully cooperative games?

A shared team reward gives no individual signal at all.

Why do learners tend to reach "safe" equilibria?

Costly exploration mistakes dissuade them from the risky, better joint action.

Which MARL challenge decides where learners end up, as opposed to how well they learn?

Equilibrium selection.

What does central Q-learning learn?

One Q-function over the state and the joint action, which controls all agents.

Why does central Q-learning scale badly?

It must explore ∣A∣N joint actions, exponential in the number of agents.

What does an independent learner's QA​(a) estimate in a one-state game?

The reward of a averaged over the partner’s current actions: ∑b​πB​(b)R(a,b).

Why do independent Q-learners end at (c, c) = 5 in the climbing game?

Averaged over the partner’s exploration, c never risks −30, so it looks best.

True or false: independent Q-learning keeps Q-learning's convergence guarantee.

False. The other learners make each agent’s environment non-stationary.

True or false: independent learners need to observe the other agents' actions.

False. Each learns from its own actions and rewards only.

True or false: tabular Q-learning needs the transition function in advance.

False. That is value iteration; Q-learning learns from sampled transitions.

True or false: the definition of a stochastic game includes an observation function for each agent.

False. The state is shared; observation functions belong to the partially observable version.

Multiple selection: which are limitations of tabular Q-learning? (A) It works only with deterministic rewards. (B) Experience in one state does not carry over to similar states. (C) It needs the transition function in advance. (D) The table grows with the number of state-action pairs.

B and D. A: the learning rate averages stochastic rewards. C: that is value iteration.

Multiple selection: which are advantages of independent learning? (A) Each agent's environment stays stationary. (B) Each Q-table covers only the agent's own actions. (C) Agents need not observe the others' actions. (D) Convergence to a Nash equilibrium is guaranteed.

B and C. A: the others’ learning makes it non-stationary. D: there are no such guarantees.

Multiple selection: which are part of a stochastic game? (A) A reward function for each agent. (B) A joint policy. (C) A transition function over the joint action. (D) An action set for each agent.

A, C and D. B: policies are what the agents choose; the game does not include them.

L04 Deep RL and Intro to Deep MARL

Flashcards

Why can a tabular Q-learner not generalise?

Each value is updated in isolation; nothing learned in one row reaches another.

What does a tabular Q-learner do in a state it never visited?

Its values are still zero, so it acts at random.

What happens to a Q-table when an irrelevant binary input is added to the state?

The rows double, and rows that differ in that input share nothing.

How does a neural network avoid the irrelevant-lamps problem?

Shared weights: what it learns about positions applies under every lamp pattern.

Name the costs of replacing a Q-table with a neural network.

Instability, possible divergence, no convergence guarantee, more computation.

What are the input and output of a standard DQN?

Input the state; output one Q-value per discrete action.

What is the DQN target when the next state is terminal?

y=r.

Which part of the deep Q-learning loss is differentiated?

Only the estimate Q(s,a;θ); the target y is treated as a constant.

What is the moving target problem in deep Q-learning?

Targets depend on θ, so every update to θ also moves the targets.

What does training on correlated consecutive experience cause?

Overfitting to recent experience and catastrophic forgetting of earlier estimates.

Which DQN component counters moving targets?

The target network, a copy updated less often.

How does DQN's replay buffer reduce correlation?

It samples minibatches uniformly from many stored transitions.

Why can DQN learn from a replay buffer of old actions?

It is off-policy: the max target ignores which policy chose the action.

Why does DQN struggle with continuous actions?

One output per discrete action; a max over infinitely many actions is an optimisation per step.

Why does the policy gradient theorem need no environment model?

It has no term for how state visit probabilities change.

What quantity does REINFORCE use to estimate the policy gradient at time t?

Gt​∇ϕ​logπ(at​∣st​;ϕ), with Gt​ the Monte Carlo return.

Why does REINFORCE have high variance?

Returns from the same state differ a lot between trajectories.

What does subtracting a state baseline do to REINFORCE's gradient?

Lowers its variance without changing its expected value.

What do actor-critic methods lose against REINFORCE?

Unbiasedness: bootstrapping from the critic adds bias.

How does A2C estimate the advantage in one step?

r+γV(s′)−V(s).

In A2C, what does a positive advantage do to the action's probability?

Raises it: the action did better than expected.

What problem does PPO's clipping address?

One update can shift the policy too far and destabilise training.

What is the ratio ρ that PPO clips?

New over old probability of the action, clipped to [1−ϵ,1+ϵ].

Which training mode trains with shared information but acts on local observations?

Centralised training with decentralised execution (CTDE).

Name the challenges of centralised training and execution.

Needs a joint reward, does not scale, agents may be distributed.

Why does IDQN's replay buffer go stale?

Its transitions reflect the other agents’ old policies.

Why do independent policy gradient methods adapt faster than IDQN?

They are on-policy and learn from the others’ current policies.

True or false: the replay buffer stores earlier copies of the network weights.

False. It stores transitions; the weight copy is the target network.

True or false: with exact Monte Carlo returns, REINFORCE's gradient estimate is biased.

False. It is unbiased; its problem is high variance.

True or false: PPO's clipping strictly guarantees that no update is harmful.

False. It limits the ratio but is no strict guarantee.

True or false: a larger replay buffer reduces outdated experience in IDQN.

False. A smaller buffer does; a larger one keeps older experience.

Multiple selection: which are on-policy? (A) DQN. (B) REINFORCE. (C) A2C. (D) PPO.

B, C and D. A: DQN is off-policy and replays old transitions.

Multiple selection: which are disadvantages of A2C compared with REINFORCE? (A) The critic is an extra component to train. (B) Bootstrapping can introduce bias. (C) It must wait until an episode ends. (D) Performance depends on critic and rollout settings.

A, B and D. C: A2C can update after a single step.

Multiple selection: which are challenges of decentralised training and execution? (A) Non-stationarity. (B) Joint action space growing exponentially. (C) Hard to coordinate. (D) Unstable learning.

A, C and D. B: that is a problem of centralised training and execution.

L05 Deep MARL, Part II

Flashcards

When is a training or execution phase called centralised?

When an agent uses centrally shared information of the others: joint history, observations, global state or joint policy.

Why does centralised training and execution scale badly?

The joint action space grows exponentially with the number of agents.

Name the disadvantages of decentralised training and execution.

Non-stationarity, suboptimal equilibria, cannot tell which changes come from other agents.

Name the disadvantages of CTDE.

Centralised training can be a bottleneck; coordination is hard when local information is insufficient at execution.

Which mode fits agents that cannot communicate when acting but have full information in a simulator?

Centralised training with decentralised execution (CTDE).

In a centralised actor-critic, which network gets the centralised information z?

The critic V(hi​,z); the actor π(ai​∣hi​) uses only the agent’s own history.

In the multi-agent policy gradient, what does the action evaluation condition on?

The full history and the joint action of all agents.

Why is a CTDE version of REINFORCE uncommon?

It has no critic, and its policy must stay decentralised, so nothing can be centralised.

What does a centralised action-value critic support that a value critic does not?

Counterfactual reasoning: my alternative actions with the others’ actions held fixed.

Which problem remains for a centralised action-value function in common-reward games?

Credit assignment: which agent’s action earned the shared reward.

What does the IGM property state?

The argmax of the joint value equals the tuple of each agent’s argmax of its own utility.

Name the two implications of IGM.

Greedy decentralised execution; cheap computation of the greedy joint action.

What does VDN assume about the reward?

The shared reward is a sum of individual reward terms.

Why does VDN satisfy IGM?

The max of a sum of separately chosen terms is the sum of their maxima.

Why can VDN not learn a task where agents must match actions?

An action’s value depends on the partner’s action, which a sum cannot express.

What condition must QMIX's mixing network satisfy?

Monotonicity: ∂Q/∂Qi​>0 for every agent’s utility.

Where do QMIX's mixing weights come from?

A hypernetwork whose input is the centralised information z (the global state).

What can neither VDN nor QMIX represent?

A game where one agent’s best action flips with the other agent’s action.

What are the input and output of agent i's deep model of agent j?

Input: agent i‘s observation history. Output: a distribution over agent j‘s actions.

How is a deep agent model trained?

Supervised, on the other agent’s observed actions (negative log-likelihood).

What does LOLA anticipate that a naive learner ignores?

The opponent’s next learning step.

When are agents weakly homogeneous?

When permuting policies between agents, for any joint policy, leaves the returns unchanged.

When are agents strongly homogeneous?

When the optimal joint policy consists of identical policies.

Which homogeneity does parameter sharing need, and which experience sharing?

Parameter sharing: strong. Experience sharing: weak.

Name two benefits of parameter sharing.

Constant parameter count as agents are added; every agent’s experience trains the shared network.

Why can experience sharing be preferred over parameter sharing?

Each agent keeps its own network, so the learned policies can differ.

What lets one shared network give different agents different behaviour?

Adding the agent index to each agent’s observation.

Name the three steps of an MCTS simulation.

Selection, expansion, backpropagation.

What does self-play require of the game?

Symmetric roles and egocentric observations, so one policy can play both sides.

True or false: CTDE agents need a central controller to choose actions at execution.

False. Shared information is used only in training.

True or false: QMIX's mixing function must be linear in each utility.

False. It must be monotonic; linear (a sum) is the VDN special case.

True or false: parameter sharing requires agents to exchange observations during execution.

False. Each agent runs its own copy of the shared network on its own observations.

Multiple selection: which statements about parameter sharing are correct? (A) All agents are constrained to the same policy (B) It works best when optimal policies differ (C) The parameter count stays constant as agents are added (D) The shared parameters learn from all agents' experience

A, C and D. B: it suits strongly homogeneous agents, whose optimal policies are identical.

Multiple selection: which are true of the IGM property? (A) Each agent can act greedily on its own utility (B) It requires a linear decomposition (C) It makes the greedy joint action cheap to compute (D) QMIX satisfies it through monotonic mixing

A, C and D. B: a monotonic mix also satisfies IGM.

Multiple selection: which methods use centralised information only during training? (A) Centralised A2C (B) VDN (C) QMIX (D) Independent DQN

A, B and C. Independent DQN uses no centralised information at all.

L06a From Deep MARL to Reasoning

Flashcards

Why are random rollouts a weak signal for MCTS in Go?

A random game says little about who wins under good play.

Which opponent do random rollouts implicitly assume?

A random one, while the agent has to beat strong players.

Which MCTS step does AlphaGo's policy network guide?

Node selection: which moves to explore.

What does AlphaGo's value network do in the search?

Estimates the chance of winning at newly expanded nodes.

How is AlphaGo's policy network first trained?

Supervised, to reproduce expert moves (cross-entropy loss).

In AlphaGo's REINFORCE stage, what happens to the moves of a lost self-play game?

All become less likely, weighted by the outcome z.

What loss trains AlphaGo's value network?

Squared error to the self-play outcome, (z−Vϕ​(s))2.

What does AlphaGo Zero drop from AlphaGo?

The expert data: it starts from a random policy and learns only by self-play.

What does AlphaZero generalise?

The same learning and search method to several games; only the game engine changes.

What does AlphaZero-style self-play assume about the two agents?

Symmetric roles, so one policy can play both sides.

Why can population-based training handle asymmetric games?

Policies in the populations can have different roles, actions and observations.

How does population-based training modify its policies?

Random changes, or copying the best performers’ parameters.

What is the PSRO meta-game?

A normal-form game whose actions are the policies in the current populations.

What are the payoffs of the PSRO meta-game?

Average returns when the policies play each other, estimated by simulation.

What does PSRO's meta-solver produce?

A distribution over each agent’s population, e.g. a Nash equilibrium of the meta-game.

How does PSRO train a new policy?

Single-agent RL against the others’ policies sampled from the meta-solution.

What kind of training is AlphaStar's league?

Population-based training with heterogeneous populations, PSRO-like.

Why are current LLMs called System 1 only?

They generate the next token without search, where AlphaGo also searches (System 2).

When text generation is framed as RL, what are the state and the action?

State: the prompt and tokens so far. Action: the next token.

True or false: AlphaGo's value network chooses which nodes MCTS explores.

False. The policy network guides selection; the value network evaluates new nodes.

True or false: in a PSRO meta-game, the actions are moves of the underlying game.

False. The actions are whole policies from the current populations.

True or false: AlphaGo Zero's policy is first trained on expert games.

False. It starts from a random policy.

Multiple selection: which are steps of PSRO? (A) Construct a meta-game from the current populations (B) Solve it with a meta-solver (C) Decompose the team value into utilities (D) Train a new policy against policies sampled from the meta-solution

A, B and D. C is value decomposition.

Multiple selection: which weaknesses of plain MCTS does AlphaGo address? (A) Heuristics need manual annotation (B) Random rollouts give a weak signal (C) Random rollouts assume random opponents (D) The game has no fixed rules

A, B and C. Go has fixed rules, which MCTS relies on.

L06b What Would Make a Chatbot an Agent

Flashcards

What does the Latin root of "agent", agere, mean?

Acting towards, driving behaviour.

What extra meaning does "agent" take on when applied to humans?

Acting on behalf of someone else.

Complete the analogy from Zacks and Tversky: objects : space = ?

Events : time.

What is an action, and what is an act, in Sileno's common-sense ontology?

An action is an event driven by an agent; an act is its completed form.

What are communication acts called?

Speech acts.

How does Dennett's physical stance interpret an entity?

Using physical laws.

How does Dennett's design stance interpret an entity?

By what it is supposed, or designed, to do.

Why does a broken clock show the limit of the design stance?

Design predictions hold only while it works; once broken, only the physical stance explains it.

Give Dennett's definition of the intentional stance.

Interpreting entities as agents, ascribing beliefs, desires, intentions and enough rationality to do what they ought to.

How do objects, actors and agents differ in Sileno's ontology?

Objects undergo changes, actors produce changes, agents are actors ascribed with intentions.

In Sileno's ontology, what turns an erupting volcano from an actor into an agent?

Ascribing it intentions, as with a fire spirit erupting because it is angry.

What are the three parts of an agent according to Newell's knowledge level?

A physical body, a body of knowledge (memory), a set of goals.

How does Sileno distinguish rationality from intelligence?

Rationality weighs explicit, verbalisable reasons; intelligence, doing the correct action in a situation, needs no verbalisation.

What is Sileno's minimal starting point for an artificial intelligent agent?

A body sensing and acting, and a mind with some memory and some purpose, possibly implicit.

Name Wooldridge and Jennings' four characteristics of weak agency.

Reactivity, proactivity, autonomy, social ability.

What distinguishes proactivity from reactivity in weak agency?

Proactivity is initiative driven by goals or intentions; reactivity is responding to environmental changes.

Which weak-agency characteristic means operating without continuous external intervention?

Autonomy.

What are the two main approaches to specifying agents' behaviour in agent-based modelling?

Cellular automata (if-then rules) and equations (possibly ODEs or PDEs).

Which agent-based modelling approach is traditionally associated with economics?

Equations, possibly differential ones.

How does agent-oriented programming (BDI agents) relate to cellular automata in agent-based modelling?

It is more expressive, but in the same arena of rule-based behaviour.

What is the rule of cellular automaton Rule 22?

A cell becomes 1 if exactly one cell in its three-cell neighbourhood is 1.

Why does network science matter for agent-based models of spreading dynamics?

The topology of who can interact with whom shapes how things spread.

How do classic and evolutionary game theory differ in their agents' rationality?

Classic: perfectly rational. Evolutionary: bounded, possibly non-rational.

How do classic and evolutionary game theory differ in the number and kind of agents?

Classic: few, different agents. Evolutionary: many, similar agents.

In Sileno's theatrical view of agency, what do EXEC, SELECT and MODIFY stand for?

Executing a script, selecting it from a repertoire, creating or adapting it.

What does SELECT presuppose in Sileno's theatrical view of agency?

A repertoire of scripts.

Where does the EXEC-SELECT-MODIFY regress end, given that SELECT and MODIFY are scripts too?

In some hard-coded ground.

What question does learning at the SELECT level ask?

Which of the available scripts is most effective?

What question does learning at the MODIFY level ask?

How do I create or rewrite a script to be more effective?

For a tit-for-tat agent, what is its SELECT rule?

Play whatever the opponent played in the previous round.

What does Bratman's chocolate example show about the desire-belief account of intention?

A fleeting predominant desire is no intention: intention requires being settled on the action.

Name the three BDI levels and their mental states.

Informational: beliefs. Volitional: desires. Deliberative: commitments (intentions).

Why does an intention include more than its goal, in the BDI model?

Committing to a conduct brings side effects besides the intended outcome.

What does an architecture lose if it lacks intention deliberation, according to Sileno?

The evaluation and weighing of possible choices.

What is intent selection (Georgeff and Rao)?

Prioritising which of several, possibly conflicting goals to advance.

What is plan selection (Georgeff and Rao)?

Prioritising which of several plans for an intent to commit to.

What categorial leap does Sileno flag between goals and plans?

A goal may be about a situation; a plan is always a conduct, a composite action.

How can the categorial leap between goals and plans be corrected?

Read the goal as achieving a situation.

In the BDI picture, what does an intention consist of?

The selected intent plus the selected plan.

What do desires set preferences about, in the full BDI picture?

Both the intent and the plans.

What must conflicting percepts be resolved into?

Consistent beliefs.

Which literatures study resolving conflicting percepts into beliefs?

Belief revision and data fusion.

What do beliefs about the current world determine in BDI deliberation?

Which plan alternatives are possible and how the intent translates concretely.

What does CAES stand for?

Commitments, abilities, expectations, susceptibilities.

Which selection or process goes with each CAES component?

Commitments: intent selection. Abilities: plan selection. Expectations: belief revision. Susceptibilities: attention allocation.

What are susceptibilities in the CAES model?

What the agent is looking at in the world, and how it responds.

Which CAES component has no counterpart in BDI?

Susceptibilities.

In a coding agent, which CAES component covers "preserve the API" and "the relevant tests pass"?

Commitments (constraint input and completion criteria).

In a coding agent, which CAES component covers watchers, interrupts and escalation routing?

Susceptibilities.

In the CAES failing-test cycle, what is the order of components?

Susceptibilities, expectations, commitments, abilities, then around again.

Why is mapping CAES onto LLM harnesses hard today?

Low-level constructs lack an interoperable declarative language; we can’t predict how the LLM interprets higher-level directives.

What is an AI agent in the common definition Sileno calls "strictly speaking wrong"?

An autonomous system where an LLM decides what to do next, which tools to use, and when the task is complete.

What is the harness, or scaffolding, of an AI agent?

Everything around the LLM: planning, memory, tool use, guardrails.

How is agentic AI commonly defined?

An autonomous system orchestrating multiple tools, including LLMs, to decide and act towards an outcome.

How does an agentic workflow differ from an autonomous agent?

In a workflow the workflow governs the agents; autonomous agents govern the workflow.

Book Ch2: Intelligent Agents

Flashcards

What is an agent, according to Russell and Norvig?

Anything that perceives its environment through sensors and acts on it through actuators.

What is a percept sequence?

The complete history of everything an agent has ever perceived.

What does an agent function map from and to?

From any percept sequence to an action.

How does the agent function differ from the agent program?

The function is an abstract mapping; the program is a concrete implementation running on a physical system.

Why does an agent program take only the current percept as input?

Nothing more is available from the environment; history must be remembered by the program itself.

What equation relates agent, architecture and program?

Agent = architecture + program.

What does a performance measure evaluate?

A sequence of environment states produced by the agent’s actions.

What notion of "the right thing" does AI mostly use for agents?

Consequentialism: behaviour is judged by its consequences.

How can a vacuum agent scored on dirt cleaned up per shift game its measure?

By dumping the dirt back on the floor and cleaning it again.

What is Russell and Norvig's rule for designing performance measures?

Measure what you actually want achieved in the environment, not how you think the agent should behave.

In the vacuum world, why did a dirt-collected reward look fine until a Dump action was added?

With only Left, Right and Suck, it produced the same behaviour as a clean-floor reward.

Name the four things rationality depends on.

Performance measure, prior knowledge of the environment, available actions, percept sequence to date.

Name one change of circumstances that makes the simple reflex vacuum agent irrational.

Each move costs a point: it keeps oscillating after both squares are clean.

Why can a simple reflex vacuum agent not stop once both squares are clean?

Its local sensor cannot see the other square, and it cannot remember having found it clean.

What does a rational agent select for each percept sequence?

An action expected to maximise its performance measure, given the percept sequence and built-in knowledge.

How does rationality differ from perfection?

Rationality maximises expected performance; perfection maximises actual performance.

Why can a rational agent not be required to be omniscient?

Knowing actual outcomes in advance is impossible, so the specification could never be met.

What is information gathering?

Doing actions in order to modify future percepts, such as looking before crossing.

What does the sphex wasp illustrate?

An agent that cannot learn that its built-in plan is failing, so it repeats it endlessly.

When does an agent lack autonomy?

When it relies on its designer’s prior knowledge instead of its own percepts and learning.

What does PEAS stand for?

Performance measure, Environment, Actuators, Sensors.

When is an environment effectively fully observable?

When the sensors detect all aspects of the state relevant to choosing an action.

When should another entity be treated as an agent rather than an object?

When its behaviour is best described as maximising a performance measure that depends on our agent’s behaviour.

Why is taxi driving both cooperative and competitive?

Avoiding collisions benefits everyone; only one car can take a parking space.

How do Russell and Norvig distinguish stochastic from nondeterministic?

Stochastic models quantify possibilities with probabilities; nondeterministic ones list possibilities without probabilities.

Why are episodic environments easier than sequential ones?

Decisions do not affect later episodes, so the agent need not think ahead.

What makes an environment semidynamic?

The environment does not change over time, but the agent’s performance score does.

Give an example of a known but partially observable environment.

Solitaire: the rules are known, but face-down cards are hidden.

Why is known vs unknown not strictly a property of the environment?

It concerns the agent’s or designer’s knowledge of the environment’s rules.

Why is the table-driven agent doomed?

The table needs an entry per percept sequence, far too many to store, build or learn.

In which environments does a simple reflex agent work correctly?

Only fully observable ones.

How can a vacuum agent with only a dirt sensor escape an infinite loop?

By randomising between Left and Right when it perceives Clean.

What two models does a model-based agent use to update its internal state?

A transition model and a sensor model.

Why is a goal-based agent more flexible than a reflex agent?

Its knowledge is explicit: changing the goal changes behaviour without rewriting rules.

Name two cases where a utility function works but goals alone do not.

Conflicting goals needing a tradeoff; several goals none of which is certain to be reached.

What is a utility function, in relation to the performance measure?

An internalisation of the performance measure.

What is a model-free agent?

One that learns which action is best in a situation without learning how actions change the environment.

What are the four components of a learning agent?

Performance element, learning element, critic, problem generator.

Why must the performance standard of a learning agent be fixed and external?

The agent must not be able to change the standard to fit its own behaviour.

What does the problem generator contribute?

Exploratory actions that may be suboptimal now but yield informative experience.

How do atomic, factored and structured states differ?

Atomic: black box. Factored: fixed set of variables with values. Structured: objects with attributes and relations.

What is gained and lost with a more expressive representation?

More concise descriptions; harder reasoning and learning.

Why are distributed representations more robust than localist ones?

Garbled bits move a concept to a nearby point with similar meaning.

Lab01: Simple Agents, Complex Dynamics

Flashcards

What payoff ordering defines a Prisoner's Dilemma?

T>R>P>S.

What payoff ordering defines a Stag Hunt?

R>T>P>S.

Which motives push to D in the Prisoner's Dilemma, and which in the Stag Hunt?

Prisoner’s Dilemma: greed (T>R) and fear (P>S). Stag Hunt: fear only.

Why is the Prisoner's Dilemma an incentive problem and the Stag Hunt a trust problem?

In the PD, D is best even against a sure cooperator; in the SH only doubt about the partner pushes to D.

What is the threshold belief p∗ for playing C in a symmetric 2x2 game?

p∗=(P−S)/((R−T)+(P−S)).

What is p∗ in the Stag Hunt with R=4,S=0,T=3,P=2?

2/3.

When do agents with uniform beliefs play (C, C) more often than (D, D) in a Stag Hunt?

When R−T>P−S: the gain beats the fear.

Why does "(C, C) is better for both, so rational agents play it" fail in the Stag Hunt?

Each agent best-responds to its own belief; C pays only if that belief exceeds p∗.

Why does Tit-for-Tat do better against AllD than AllC does?

It conditions on the partner’s last move, so it is exploited only in round 1.

Why does AllD exploit WSLS every other round?

WSLS counts mutual defection as a loss and switches back to C.

Why can AllD win a tournament that includes AllC and Random?

Its points come from exploiting unconditional or random cooperators.

In a Prisoner's Dilemma population, why is fC​−fD​ negative for every x?

It equals x(R−T)+(1−x)(S−P), and greed and fear make both terms negative.

Why does the Stag Hunt's replicator tipping point equal the threshold belief p∗?

Under random matching the cooperator share is the probability the partner cooperates.

True or false: a Stag Hunt population (R = 4, S = 0, T = 3, P = 2) starting with 60% stag hunters ends with everyone hunting stag.

False. At 60%, hare earns 2.6 against stag’s 2.4, so stag hunting dies out.

True or false: making Prisoner's Dilemma agents sure that their partner cooperates makes them cooperate.

False. Greed remains: against a sure cooperator, D still pays T>R.

Multiple selection: which strategies cooperate at different rates depending on the opponent? (A) AllC (B) TFT (C) Random (D) WSLS

B and D. Both are memory-1. A and C are memory-0 and cannot react.

Lab02: Learning Agents

Flashcards

What is the stateless Q-learning update?

Q(a)←Q(a)+α(r−Q(a)), only for the action just played.

Why can the γmaxa′​Q(s′,a′) term be dropped in a repeated game with one state?

It adds the same amount to both actions’ targets, so it never changes which is greedy.

In the Stag Hunt with R=4,S=0,T=3,P=2, what do C and D earn against a 50/50 partner?

C earns 2, D earns 2.5.

Why do Stag Hunt Q-learners starting at Q=(0,0) lock into (D,D)?

Once the partner plays D, C pays 0, so Q(C) never sees that C can pay 4.

With Q(C)=4b and Q(D)=3b+2(1−b) in the Stag Hunt, when does an agent start with C?

When b>2/3.

An optimist (belief 0.9) meets a sceptic (belief 0.5) as Q-learners in the Stag Hunt. Who adapts?

The optimist: its C earns 0, so its Q(C) falls until D is greedy.

With a constant learning rate, what does a stateless Q-learner's Q(a) estimate?

An exponentially weighted average of the recent payoffs of a.

Why do Q-learners leave (C,C) in the Stag Hunt although C is the best response?

The partner’s exploratory D moves pay 0, and a few zeros push Q(C) below Q(D).

Why is escaping from (D,D) to (C,C) far rarer than the reverse?

C pays 4 only when both explore C in the same round, and both must switch together.

Why is the Prisoner's Dilemma learners' (D,D) not a coordination failure?

D is dominant, so (D,D) is the only Nash equilibrium: a social dilemma.

In the Coin Game, what happens when an agent takes the other player's coin?

The picker gets +1 and the coin’s owner gets −2.

Why does a self-interested Coin Game agent take every reachable coin?

The −2 falls on the other agent, so its own reward ignores that cost.

What is the expected total reward per pickup when both Coin Game agents are colour-blind?

0: half the pickups add +1, half add −1.

Why can independent Q-learners not learn restraint in the Coin Game?

The state holds no record of the other’s behaviour, so restraint cannot be reciprocated.

How many rows does the Coin Game Q-table have with k irrelevant lamps?

1,458⋅2k.

How is the training budget B of the Coin Game counted?

Decisions per agent: updates × parallel games × steps per episode.

Why can a Q-table not discover that the lamps do not matter?

Rows share nothing: each lamp pattern must be learned separately.

Complete for the Coin Game: "Deep RL solved ..., but not ...".

Generalisation over irrelevant inputs, but not the social dilemma.

True or false: more exploration helps Stag Hunt Q-learners reach (C,C).

False. Exploration knocks them out of (C,C) and leaves (D,D) intact.

Multiple selection: why do Stag Hunt Q-learners starting at zero mostly end at (D,D)? (A) D earns more against a 50/50 partner. (B) D is dominant. (C) C pays 0 whenever the partner plays D. (D) (D,D) is risk-dominant.

A, C and D. B: against C, stag (4) beats hare (3), so D is not dominant.
