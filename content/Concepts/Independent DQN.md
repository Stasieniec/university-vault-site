# Independent DQN

## Definition

> [!definition] Independent DQN (IDQN)
> The deep version of independent Q-learning: **each agent $i$ trains its own [[Deep Q-Network (DQN)|DQN]]**, an action-value network $Q(\cdot\,;\theta_i)$ with its own [[Target Network|target network]] and [[Experience Replay|replay buffer]], on its own observation history and reward, and treats the other agents as part of the environment. It belongs to decentralised training and execution ([[Centralised Training with Decentralised Execution|DTDE]]).

## Intuition

> [!intuition] A diary of a world that no longer exists
> DQN's replay buffer is a diary of past transitions, replayed for training. With one agent the diary stays true: the environment's rules do not change, only the agent's own behaviour, which Q-learning's off-policy target can handle. With several learners the other agents are part of the environment, and they keep changing. An entry from a thousand steps ago records how they used to play, so replaying it teaches agent $i$ about opponents or teammates that are gone.

## Mathematical Formulation

Agent $i$ minimises, over minibatches of $B$ transitions $(h_i^k, a_i^k, r_i^k, h_i^{k+1})$ sampled from its own buffer $\mathcal{D}_i$:

$$\mathcal{L}(\theta_i) = \frac{1}{B}\sum_{k=1}^{B}\Big(y_i^k - Q(h_i^k, a_i^k;\theta_i)\Big)^2, \qquad y_i^k = \begin{cases} r_i^k & \text{if terminal}\\ r_i^k + \gamma\max_{a_i'}Q(h_i^{k+1}, a_i';\bar\theta_i) & \text{otherwise}\end{cases}$$

where:
- $h_i^k$: agent $i$'s observation history; $a_i^k$: its own action (the others' actions are not stored)
- $r_i^k$: its own reward (in a cooperative task, the shared team reward)
- $\theta_i$, $\bar\theta_i$: its value network and target network, copied at set intervals

Each step, every agent chooses ε-greedily from its own network, the joint action is applied, and each agent stores its own transition and runs this update.

## Key Properties / Variants

- **Outdated experience.** Transitions in $\mathcal{D}_i$ were generated while the others used older policies; once they change, those transitions may no longer reflect the environment agent $i$ now faces. Off-policy learning makes agent $i$'s own old actions harmless, but the others' old behaviour is part of agent $i$'s environment, and that has changed.
- **Fix 1: smaller replay buffers,** which keep only recent experience from policies close to the others' current ones. A larger buffer makes the problem worse.
- **Fix 2 (MARL book, Ch 9): importance sampling weights.** Store the agents' action probabilities with each transition and reweight replayed transitions by the ratio of the other agents' current to stored probabilities ([[Importance Sampling]]).
- **Against independent policy gradients:** independent REINFORCE, IA2C and IPPO are on-policy, so they always learn from experience generated by the others' current policies and adapt faster; their weakness is amplified variance instead.
- **Inherits independent learning's issues:** non-stationarity, no convergence guarantee, miscoordination, but scales to many agents since each network covers only its own actions.
